Auto Drill: Galaxy

보유 스킬 0개

첫 프레스티지 후 보스 연계: Basic Drill + Plasma Cutter → 굴착 공명, Laser Pointer + Auto Cannon → 집중 포화, Lucky Strike + Targeting OS → 정밀 동기화. 서로 다른 두 스킬을 모으면 해당 보스 약점 단계의 피해 +10%. 중복으로 더 증가하지 않습니다.

갤럭시 상점

상품을 준비하고 있습니다.

함선 연구소

첫 프레스티지 이후 보스 공략

체력 50%에서 단계가 바뀝니다. 철갑 채굴자: 채굴 → 전투, 수정 파수꾼: 균형 → 채굴, 공허 수호자: 전투 → 균형 모듈에 약점이 있습니다. 약점 모듈은 피해 배율 +0.25, 해당 스킬 연계는 +0.10. 보스는 전환 없이도 격파할 수 있습니다.

이번 항해 모듈

동시에 1개 적용 · 전환은 무료, 적용 후 10초 대기. 효과는 파츠 능력치에 적용됩니다. 스킬·암흑물질 효과는 그대로 유지됩니다.

프레스티지 시 플라스마와 모듈 단계가 초기화됩니다. 강화 비용은 환불되지 않습니다.

영구 연구

유물 잔량과 연구 단계는 프레스티지 후에도 유지됩니다. 탐지기는 채굴량을 높입니다. 강화 비용은 환불되지 않습니다.

탐사 기록

첫 프레스티지 이후의 도전입니다. 기한 없이 원하는 속도로 탐사하세요.

집계·저장 안내

과제는 순서대로 수령합니다. 진행과 수령 기록은 프레스티지 후에도 유지됩니다.

항해 계약

계약은 해당 모듈로 실제 플레이할 때 진행됩니다. 오프라인·광고·미션 보상은 집계되지 않습니다.

영구 목표 · 각 유물 +1

영구 목표와 수령 기록은 프레스티지 후에도 유지됩니다. 기존 저장에서 보스·전경 채굴 기록은 이번 업데이트 이후부터 집계합니다.

심우주 항로

도전하고 빔·궤도 외형을 모으세요. 외형은 능력치에 영향을 주지 않습니다.

집계·저장 안내

모듈 도전은 항로 해금 이후 직접 플레이할 때 집계합니다. 오프라인·광고 보상은 제외하며, 모든 진행과 외형은 프레스티지 후에도 유지됩니다.

목표 추적은 메인 화면 안내용입니다. 언제든 바꿀 수 있고 다른 목표의 진행도도 유지됩니다. 서포터 함선 색상과 함께 사용할 수 있습니다.

설정 · 도움말

번역 적용 준비 중입니다. 일부 콘텐츠·알림은 아직 한국어로 표시됩니다.

소리와 화면

설정은 자동 저장되고 백업 코드에도 포함됩니다. 이 설정은 게임 효과음에 적용됩니다. 광고 소리는 광고 화면이나 기기 음량으로 조절하세요.

게임 도움말

아래 항목을 펼쳐 언제든 다시 읽을 수 있습니다. 게임은 도움말을 읽는 동안에도 계속 진행됩니다.

처음에는 무엇을 하나요?

함선은 자동으로 광석을 채굴하고 소행성을 공격합니다. 광석 50개로 첫 스킬을 뽑으세요. 이후 뽑기 비용은 보유 스킬 수에 따라 올라갑니다.

파츠와 연구소는 어떻게 강화하나요?

철 5개와 수정 2개를 모아 합성하면 엔진과 리액터가 강화됩니다. 연구소에서는 플라스마로 이번 항해 모듈을, 유물로 영구 연구를 강화합니다. 모듈은 동시에 하나만 적용되며 전환 후 10초 동안 다시 바꿀 수 없습니다.

프레스티지하면 무엇이 남나요?

화면의 목표 웨이브에 도달하면 암흑물질을 얻고 새 항해를 시작할 수 있습니다. 광석·철·수정·플라스마·모듈·항해 계약은 초기화됩니다. 파츠·스킬·암흑물질·유물·영구 연구·영구 목표 수령 기록·항로 외형은 유지됩니다.

보스와 스킬 연계는 어떻게 공략하나요?

5웨이브마다 보스가 등장합니다. 첫 프레스티지 이후 체력 50%에서 약점 모듈이 바뀝니다. 보스 아래의 약점 안내와 연구소의 예상 피해를 비교하세요. 연계에 필요한 서로 다른 스킬 2종을 모으면 해당 단계의 피해가 증가합니다. 모듈을 전환하지 않아도 보스를 격파할 수 있습니다.

앱을 꺼도 진행되나요?

떠날 때의 채굴량으로 최대 4시간의 광석을 정산합니다. 오프라인에서는 전투·계약·항로 숙련이 진행되지 않습니다. 앱 삭제나 기기 변경 전에는 저장 · 백업 / 복원에서 백업 코드를 따로 보관하세요. 구매 복원은 상점에서 이용하며 게임 진행 복원과 별개입니다.

저장과 복원

진행은 이 기기에 저장됩니다. 앱 삭제·기기 변경에 대비해 백업 코드를 따로 보관하세요. 자동 클라우드 동기화는 지원하지 않습니다.

유료 상품은 백업에 포함되지 않습니다. 같은 스토어 계정으로 상점의 구매 복원을 이용하세요.

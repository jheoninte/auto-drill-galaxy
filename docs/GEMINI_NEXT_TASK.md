# Gemini 위임 기록: 첫 세션 경제 재설계

이 프롬프트의 1차 결과는 반영·보정되었다. 아래 내용은 당시 위임 기록이다.
현재 값과 실제 결과는 `docs/BALANCE_REVIEW.md`를 기준으로 하며 아래 이전 수치를 다시 적용하지 않는다.

아래를 Gemini에 전달하고 현재 `web-prototype/game/balance.js`를 함께 참고시킨다.

```text
Auto Drill: Galaxy는 iOS 우선, 기본 무료 IAP+IAA 하이브리드 캐주얼 게임이다.
자체 서버 없이 진행하고, 광고/IAP가 없어도 핵심 루프를 즐길 수 있어야 한다.
이번 작업은 경제 수치와 짧은 튜토리얼 기획이다. HTML/SDK 코드는 작성하지 마라.

이전 제안은 실제 게임 시스템으로 시뮬레이션했으며 예상보다 너무 빨랐다.
20개 고정 시드, 1배속, 0.25초 간격, 광석 50개마다 즉시 가챠,
재료 충족 시 즉시 머지, 프레스티지 미실행 조건의 중앙값:
첫 가챠 20초 / 첫 머지 119.75초 / wave 8 진입 138.75초 / wave 15 진입 207.5초.

현재 규칙:
- 채굴/초 = 1.8 + engine*0.45 + reactor*0.25 + darkMatter*0.35 + miningBonus 합
- 기본 피해/초 = 4.5 + hull*0.4 + reactor*0.8 + darkMatter*0.5 + damageBonus 합
- crit = min(0.65, 0.08 + darkMatter*0.01 + critBonus 합)
- 실제 연속 피해/초 = 기본 피해 * (1 + crit*1.2)
- 초기 파츠 각 1, HP = 150 + (wave-1)*30
- 클리어 보상 ore=20+wave*4, 재료 독립 2회 (철45/수정27/플라스마21/유물7%)
- 가챠 50 ore 고정, 12종 가중 추첨, 중복 효과 무제한 가산
- 합성 철5+수정2, engine/reactor 각 +1
- wave가 4의 배수에 진입하면 hull+1
- wave8 프레스티지 해금, 보상 floor(wave/4)
- 프레스티지 후 파츠/스킬/darkMatter 유지, ore/재료/현재 wave 초기화
- 보상형 광고는 선택 시 60초 채굴량, 3분 간격. 목표 시간은 광고 미사용 기준
- IAP는 광고 제거와 외형, 경제 성장 보너스 없음

목표:
첫 가챠 20~40초, 첫 합성 3~5분, 첫 프레스티지 해금 10~15분.
프레스티지 해금 시간과 유저가 실제 누르는 시간을 구분한다.
광고를 강제하거나 불편함을 판매해 목표 시간을 맞추지 마라.

제출:
1. HP/보상/가챠 비용 상승/중복 효과/프레스티지 유지 정책을 고려한 수치안 2개
2. 각 안의 정확한 공식과 파라미터 JSON, 추천 1안과 이유
3. 추천안의 wave1~20 CSV (wave,hp,ore_reward,material_drops)
4. 자동 구매/수동 플레이 가정별 1/5/10/15/30분 진행 예상표
5. 반복 프레스티지 무한 가속 위험과 제한 방안
6. 첫 3분 안내 문구 6개 이내와 표시 조건

실제 실행한 시뮬레이션과 단순 추정을 구분하고, 실행했다면 재현 가능한 코드와 시드/정책을 제시해라.
초기 DPS 고정 나눗셈으로 가챠 재투자 성장을 추정하지 마라.
설명은 짧게 하고 공식과 데이터 중심으로 답해라.
```

# Gemini 경제 재설계 검증

## 적용 데이터

- 런타임 데이터: `web-prototype/game/balance.js`
- 웨이브 1~20 표: `tools/balance_sheet.csv`
- 일반 HP: `floor(150 * 1.2 ** (wave - 1))`, 21 이후에도 같은 공식 유지
- 보스: 매 5웨이브, HP 공식에 1.35배 적용. 이름/외형/체력바 구분
- 클리어 보상: 일반 `20 + wave * 5` ore, 보스는 그 값의 1.5배를 내림
- 보스 확정 추가 재료: 플라스마 1개, 10의 배수 웨이브는 유물도 1개
- 재료: 클리어당 1개. 첫 플레이 웨이브 1~8은 철/수정/철/플라스마/철/수정/철/철 보장
- 이후 및 프레스티지 후 재료: iron/crystal/plasma/relic 확률 45/27/21/7%
- 가챠: 12종, 제공받은 weight로 가중 추첨, 중복 효과 누적
- 가챠 비용: `floor(50 * 1.15 ** skills.length)`. 첫 50, 다음 57, 다음 66. 스킬 유지와 함께 누적 비용도 유지
- 치명타: 평균 배율 `1 + chance * (2.2 - 1)`을 피해에 적용. 연속 피해 모델에서 프레임별 확률 차이를 제거
- 프레스티지: `18 + 2 * floor(runs / 3)` 웨이브부터 가능, `floor(wave / 4)` darkMatter 획득
- 선체 보상: 최고 기록을 처음 갱신하는 4의 배수 웨이브 진입 때만 +1 (반복 항해 중복 지급 없음)
- 암흑물질 효과: `effect = darkMatter / (darkMatter + 10)`, 채굴·기본 공격에 `1 + effect` 곱함 (최대 2배)
- 치명타 확률: `min(0.65, 0.08 + effect * 0.01 + 스킬 보너스 합)`
- 초기화: ore, iron/crystal/plasma, 항해 모듈 단계·선택·전환 대기, 현재 웨이브와 HP
- 유지: relic 잔량과 영구 연구 단계 (연구소 추가 이후 정책)
- 유지: 파츠, 스킬, darkMatter, 최고 웨이브, 누적 채굴량
- 기존 v2 세이브: 웨이브와 HP 비율을 유지하며 새 HP로 환산

## 실행 검증

`node scripts/simulate-balance.mjs`

실제 게임 시스템으로 고정 시드 1~20을 실행했다. 새 게임, 1배속, 0.25초 간격,
현재 비용을 충족할 때마다 즉시 가챠, 재료 충족 시 즉시 머지, 아래 첫 도달 표에서는 프레스티지를 실행하지 않는다.
각 시드 30분까지 실행한다. 중앙값은 정렬한 20개 중 상위 가운데 값이다. 광고는 사용하지 않는다.

| 지점 | 중앙값 | 최소~최대 |
| --- | --- | --- |
| 첫 가챠 | 20초 | 20~20초 |
| 첫 머지 | 218초 | 169.5~248.5초 |
| 웨이브 8 진입 | 183.75초 | 149.25~216.5초 |
| 웨이브 15 진입 | 508.25초 | 382.25~612.25초 |
| 프레스티지 해금 (wave 18) | 770.75초 | 564~908.75초 |

## Gemini 원안에서 수정한 이유

원안의 HP 지수 증가·가챠 비용 상승만 적용하면 wave 8 해금 중앙값은 178.5초였다.
첫 머지는 325.25초이며 재료 운에 따라 1164.25초까지 지연되었다.
초반 확정 재료와 wave 18 해금으로 이 편차와 시점을 조정했다.
제공된 CSV는 wave 11 이후 공식과 달라 공식에서 계산한 값으로 교정했다.

## 30분 반복 세션

매 해금마다 즉시 프레스티지를 실행한다. 아래 각 열은 독립적인 중앙값이며 하나의 플레이 기록이 아니다.
30초 정책은 30초마다 구매 가능한 스킬/합성을 모두 실행하는 규칙이며 실제 사람의 수동 플레이 측정이 아니다.

| 분 | 즉시 구매: 웨이브 / 스킬 / 프레스티지 횟수 | 30초마다 결정: 웨이브 / 스킬 / 프레스티지 횟수 |
| --- | --- | --- |
| 1 | 3 / 3 / 0 | 3 / 3 / 0 |
| 5 | 11 / 14 / 0 | 10 / 13 / 0 |
| 10 | 15 / 20 / 0 | 15 / 20 / 0 |
| 15 | 12 / 24 / 1 | 12 / 24 / 1 |
| 30 | 16 / 32 / 4 | 15 / 32 / 4 |

2026-11-17 장기 경제 수정 후 결과다. 수정 이전 30분 환생 중앙값은 5회였다.
첫 도달 수치는 유지된다. 장기 비교와 미션 정책은 `EXPEDITION_REVIEW.md`를 참고한다.

초반 목표는 중앙값 기준으로 충족하지만 모든 시드가 목표 구간 안에 드는 것은 아니다.
암흑물질 효과의 상한이 파츠·스킬 영구 누적까지 제한하는 것은 아니다.
24시간 모델 검사는 완료했으며 실제 사용자 반복 플레이 감각과 24시간 이후 정체/가속은 후속 검증 대상이다.
실제 사용자 리텐션이나 광고 수익이 검증된 수치는 아니다. 기존 세이브를 삭제하지 않으며 위 시간은 새 게임 기준이다.

## 첫 세션 안내

`game/tutorial.js`에 6개 조건 기반 안내를 둔다. 메시지마다 4초 표시하고 동시에 조건이 충족돼도 순차 표시한다.
표시한 ID를 세이브에 저장해 재접속·프레스티지 때 반복하지 않는다. 상점·플랫폼 작업·백그라운드 동안 표시 시간을 진행하지 않는다.
뽑기/합성/프레스티지 버튼을 강조하고 다음 목표와 현재 가챠 비용을 HUD에 표시한다.

## 전투와 성장 피드백

- 보스 3종 이름 순환: 철갑 채굴자 / 수정 파수꾼 / 공허 수호자. 현재 공격 패턴은 공통 자동 피해 모델
- 보스 보상은 게임 시스템에서 지급하고 반환 이벤트로 UI에 전달. 카드 표시는 보상을 재지급하지 않음
- 뽑기 카드는 희귀도·보유 중첩·실제 증가한 능력치를 4.5초 표시. 치명타 상한에서는 효과 없음 안내
- 합성은 엔진/리액터의 새 레벨과 증가량, 프레스티지는 획득 암흑물질을 표시
- 카드는 플레이를 차단하지 않으며 새 획득 시 최신 결과로 교체. 표시 중 튜토리얼 시간을 일시정지
- 효과음은 Web Audio 합성음이며 기본 꺼짐. 사용자 조작 이후에만 오디오 초기화, 설정 저장 및 백그라운드 시 중단
- 모션 줄이기 설정에서는 함선 공전 연출과 파괴 링을 생략. 실제 전투/채굴 속도에는 영향 없음
- 보스 패턴과 장기 경제는 후속 개발 대상. 플라스마/유물 소비처는 연구소에 구현 (`WORKSHOP_REVIEW.md`).

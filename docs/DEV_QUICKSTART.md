# DEV QUICKSTART

## 목표

- 자동 채굴 수식, 전투 연출, 메타 성장 구조를 분리해 바로 기능 개발이 가능하도록 합니다.
- 현재 HTML5 검증본을 기준으로 후속 엔진 포팅이 가능한 데이터 구조를 유지합니다.

## 실행

```bash
npm install
npm run dev
```

## 추천 첫 작업 순서

1. `web-prototype/index.html`에서 채굴 루프와 전투 연출을 분리합니다.
2. `docs/PROGRESSION_SCHEMA.json` 기준으로 업그레이드/가챠/프레스티지 데이터 접근 계층을 만듭니다.
3. 오프라인 보상 계산을 `lastSeenAt` 기반 서비스로 분리합니다.
4. `tools/balance_sheet.csv`를 읽는 밸런스 검증 스크립트를 추가합니다.

## 첫 스프린트 산출물

- 리소스 생산 공식 모듈화
- 전투 웨이브 및 적 스폰 설정 분리
- 업그레이드 비용 테이블 구조화
- 세이브 포맷 문서와 실제 키 동기화

# 보스 단계와 스킬 연계

2026-11-17. 첫 프레스티지 이후 보스에 체력 기반 두 단계와 모듈 약점을 추가했다.
이번 Gemini 앱은 다른 프로젝트의 답변을 생성 중이어서 새 프롬프트를 보내지 않았다.
기존 세 보스 이름을 유지하고 Codex가 제한된 콘텐츠와 런타임을 구현했다.

## 전투 규칙

보스는 5웨이브마다 등장하며 세 종류가 순환한다. 첫 항해에는 기존 자동 전투를 유지한다.
첫 환생 이후 체력 50%를 기준으로 다음 단계를 사용한다. 시간 제한·즉사·무적은 없다.

| 보스 | 체력 50% 초과: 기본 피해 배율 / 약점 모듈 | 50% 이하: 기본 피해 배율 / 약점 모듈 |
| --- | --- | --- |
| 철갑 채굴자 | 장갑 굴착: 0.85 / 채굴 | 노심 노출: 1.15 / 전투 |
| 수정 파수꾼 | 수정 공명: 0.90 / 균형 | 균열 확장: 1.10 / 채굴 |
| 공허 수호자 | 공허 응축: 0.90 / 전투 | 위상 붕괴: 1.10 / 균형 |

해당 모듈을 1단계 이상 구매하고 활성화하면 단계 배율에 0.25를 더한다.
다음의 서로 다른 두 스킬을 보유하면 연결된 약점 단계 배율에 0.10을 더한다.

| 연계 | 필요 스킬 | 연결 모듈 |
| --- | --- | --- |
| 굴착 공명 | Basic Drill + Plasma Cutter | 채굴 |
| 집중 포화 | Laser Pointer + Auto Cannon | 전투 |
| 정밀 동기화 | Lucky Strike + Targeting OS | 균형 |

연계는 해당 스킬 ID를 각각 하나 이상 보유할 때 활성화된다. 동일 스킬 중복으로 증가하지 않는다.
연계 보너스는 모듈을 적용하지 않아도 해당 단계에서 작동한다. 원래 스킬의 가산 능력치는 유지한다.
최종 피해/초 = 기존 공격/초 × 평균 치명타 배율 × (단계 기본 배율 + 모듈 보너스 + 연계 보너스).
단계 배율은 0.85~1.50이다. 기존 모듈 전환 10초 대기와 환생 초기화 규칙을 유지한다.
모듈의 원래 공격/채굴 효과가 있으므로 약점 모듈이 언제나 가장 높은 DPS를 보장하지 않는다.
연구소에서 각 보유 모듈을 적용했을 때의 현 단계 예상 피해를 비교할 수 있다.

이 변경으로 보스 보상·일반 적·채굴·오프라인 보상은 추가하지 않는다.
단계는 저장된 웨이브와 체력 비율에서 계산하므로 새 저장 필드나 타이머가 필요 없다.
화면에 단계명·모듈 약점·실제 배율·연계를 표시하고 외곽선 색과 패턴을 구분한다.
보스 안내가 캔버스를 가리지 않도록 해당 전투 장면 최소 높이를 280px로 확보한다.

## 전투 시간 처리와 검증

한 업데이트가 단계 경계나 적 격파를 넘으면 남은 **시간**을 다음 구간에 사용한다.
남은 피해를 다른 배율의 적에게 그대로 넘기지 않는다. 격파 후 새 파츠 능력치도 재계산한다.
이 보정 때문에 첫 항해에서도 파츠 지급 프레임의 미세한 차이가 있다.

- `npm run check`: 단계 경계·큰 업데이트와 작은 업데이트의 동등성·모듈 구매/전환 대기·서로 다른 스킬 조합·저장 왕복·오프라인 제외·보상 1회 검사를 포함해 통과.
- `npm run balance`: 20시드, 첫 뽑기 20초·첫 합성 218초·기본 정책 첫 환생 해금 764.5초 중앙값. 이전 770.75초 대비 약 0.8% 단축, 목표 10~15분 범위 유지. 채굴/전투/균형 모듈 정책은 각각 792.5/703.25/748.25초.
- `npm run balance:bosses`: 20시드, 1초 단위, 24시간, 광고/구매 없음. `tools/reports/long-term-bosses.json`에 기록하며 이전 보고서는 덮어쓰지 않는다.

기존 고정 모듈 정책은 보스 약점에 맞춰 자동 전환하지 않는다. 항로 순환 정책은 채굴 과제 완료 후
전투, 전투 과제 완료 후 균형 모듈로 전환한다. 이는 프레임마다 최적 행동을 하는 모델이며 사람의 행동과 다르다.

| 정책 | 24시간 환생 중앙값 | 최고 웨이브 중앙값 | 최소 항해 시간(20시드 전체) |
| --- | --- | --- | --- |
| 채굴 고정, 계약 미수령 | 46 | 48 | 172초 |
| 전투 고정, 계약 미수령 | 48 | 48 | 133초 |
| 균형 고정, 계약/목표 수령 | 47 | 48 | 197초 |
| 항로 과제 순차 전환 | 47 | 48 | 167초 |
| 4시간마다 5분, 6회 접속 | 8 | 22 | 94초 |

항로 순차 전환에서 웨이브 40 도달 중앙값은 26,998초(약 7.50시간), 항로 7종 달성은
20/20시드였다. 짧은 접속 정책은 첫날 항로 수령 중앙값 0개로 여전히 개선 검토가 필요하다.
전체 정책에서 진행 정체와 60초 미만 환생 반복은 없었다. 이 결과로 리텐션 개선을 주장하지 않는다.

## 화면 확인과 남은 검증

별도 로컬 주소의 테스트 백업으로 수정 파수꾼의 전/후반 안내, 모듈 전환·10초 대기,
예상 피해, 재시작 후 후반 단계 유지와 320/390px 가로 넘침을 확인했다.
`mobile-boss-preview.jpg`는 인위적으로 준비한 QA 저장 화면이며 사용자 실제 진행이 아니다.
원래 저장은 테스트 후 복원했다.

iPhone에서 단계 변경 가독성, 터치/스크롤, 광고 중단/강제 종료 후 단계 유지,
발열과 프레임을 검증해야 한다. 신규 사용자가 연계를 이해하는지, 모듈 전환이 실제로 재미있는지,
무작위 스킬 수집만으로 조합 선택이 충분한지는 실제 플레이테스트 과제다.

# 출시 비주얼 방향과 에셋 목록

방향 확정: **네온 궤도 채굴 / Neon Orbit Mining**.
차분한 짙은 우주 위에서 드릴의 빛과 명확한 성장 피드백이 중심이다.
벡터에 가까운 선명한 도형, 둥근 패널, 간결한 기술 도해 스타일로 통일한다.
고해상도 일러스트·복잡한 3D·픽셀 아트는 현재 제작 범위에 넣지 않는다.

## 공통 규격

- 배경 `#020617`, 패널 `#0f172a`, 기본 글자 `#e2e8f0`, 보조 글자 `#cbd5e1`.
- 채굴/선택 `#67e8f9`, 보스/재료 `#fbbf24`, 전투 `#fb7185`, 영구/고급 연구 `#c4b5fd`.
- 희귀도는 N/R/SR/UR 문자와 테두리 패턴을 병행한다. 색만으로 등급/상태/모듈을 전달하지 않는다.
- 한국어·영어·일본어 문자는 이미지에 굽지 않는다. 텍스트는 DOM, 아이콘은 독립 에셋이다.
- 장식보다 44pt 이상 터치 영역과 읽을 수 있는 비용/보상을 우선한다. 모션 줄이기에서 의미를 잃지 않게 한다.
- 영상/전면 섬광/상시 흔들림은 사용하지 않는다. 채굴 표면의 작은 파편·접점 맥동과 짧은 뽑기·합성·보스 격파 강조를 사용한다. 모션 줄이기는 파편·맥동을 끈다.
- 초안은 Canvas/SVG/CSS로 구현한다. 래스터 교체 시 투명 캐릭터 PNG/WebP, 배경 불투명 WebP, 원본은 별도 보관한다.
- 크기 숫자는 제작용 기준이며 최종 iPhone 메모리/번들 크기로 검증한다. 아래 수량은 논리 에셋 수이고 PNG 파일 수가 아니다.

## 사운드: 기본 7종 + 뽑기 변형 2종

`web-prototype/ui/sound-bank.js`의 합성음 데이터를 사용한다.

| 이벤트 | 방향 | 구현 |
| --- | --- | --- |
| 일반 뽑기 | 밝은 3음 상승 | 연결됨 |
| SR / UR 뽑기 | 각각 4음 / 5음 상승 | 연결됨, 총 변형 2종 |
| 합성 | 낮은 음에서 안정된 상승 | 연결됨 |
| 보스 격파 | 묵직한 3음 해결 | 연결됨 |
| 환생 | 넓은 음역 5음 상승 | 연결됨 |
| 연구/모듈 강화 | 짧은 기술음 | 연결됨 |
| 보상 수령 | 짧은 2음 보상음 | 연결됨 |
| 모듈/외형/추적 선택 | 작은 2음 확인음 | 연결됨 |

길이는 약 0.3~0.6초, 동시 발진기 최대 16개다. 매 채굴·매 타격마다 소리를 재생하지 않는다.
실패/부족/광고 거부에는 벌점처럼 들리는 경고음을 반복하지 않고 문구로 안내한다.
루프 음악·음성·진동은 첫 출시 핵심 범위에서 제외하고, 진동 도입 여부는 Mac 실기기 단계에서 재검토한다.
합성음은 외부 녹음 샘플을 포함하지 않는다. 추후 교체 파일은 출처/라이선스/수정 내역을 함께 기록한다.

## 제작 순서

지금: 형태/색/라벨과 사운드 이벤트 일관성 → 한영일 문구/실제 데이터 연결 → 모바일 가독성.
나중: 승인한 스타일로 그래픽 교체 → 앱 아이콘 → iPhone 축소/성능 확인 → 스토어 이미지.
Gemini는 스타일·문구·변형 아이디어를 제공하고, 실제 에셋 생성/삽입과 수치 검증은 별도 작업으로 수행한다.

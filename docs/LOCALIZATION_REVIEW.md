# 동적 문구·오류·복귀 알림 현지화

2026-11-17 Windows 구현/브라우저 검증 기록. 한국어·영어·일본어 공통 키를 247→398개로 확장했다.
5구역/30과제의 데이터 내 번역은 이 키 수와 별도다. 번역은 검수 전 초안이며 원어민 검수 완료가 아니다.

## 연결한 범위

- 연구소: 3모듈/4연구의 현재·다음 효과, 비용·최대 단계·적용·전환 대기·보스별 예상 피해와 강화 결과.
- 탐사: 영구 목표 7개와 계약 3개의 이름·조건·진행·보상·수령 결과, 환생 전 미수령 계약 안내.
- 항로: 기존 7종과 추가 8종 전체 카드·외형명·추적·해금·적용·현재 외형·메인 추적 목표.
- 공통 플랫폼 결과: 앱 전용·연결 실패·진행 중·구매 대기/실패/검증/복원·보상 중복/미완료·개인정보 재선택 결과.
- 저장: 크기·형식·버전·손상 오류, 자동 백업 복구·원본 보존·저장 실패·복원 안내.
- 세션: 웨이브/보스 보상과 오프라인 시간·광석 알림. 화면 언어 변경 시 마지막 알림도 다시 번역한다.
- 도움말: 연구 4종 역할과 연계 6종의 실제 스킬 쌍·동일 모듈 연계 합계 상한을 표시한다.

## 상태와 서비스 경계

게임/플랫폼 함수는 기존 한국어 `message`와 함께 안정된 `messageKey`, 숫자 매개변수,
표시 이름용 `messageParamKeys`를 반환한다. 한국어 문자열은 기존 코드/검사와의 호환용이며
화면은 `i18n/result.js`에서 현재 언어로 해석한다. 렌더링이 결과 객체나 경제 수치를 수정하지 않는다.

`session.lastRewardEvent`는 세션 메모리에만 두고 백업/저장에는 포함하지 않는다.
오프라인 복귀의 보상 수식·4시간 상한·부재 시 모듈 스냅샷 정산은 그대로다.
웨이브 보상·단계별 예상 피해·연구 배율도 이번 변경으로 조정하지 않았다.

저장 오류는 `Error.messageKey`로 분류한다. 상위 버전 저장의 자동 덮어쓰기 금지와
쓰기 실패 후 알림 해제에 번역 문장 검색을 사용하지 않는다. 알 수 없는 저장소 예외는
화면에 기기 저장소 접근 안내로 표시한다. 백업 복원 직후 알림도 복원된 언어를 따른다.

브라우저는 네이티브 구매·광고·UMP 성공을 재현하지 않는다. 플랫폼 단위 검사에만 테스트 제공자를 사용한다.
실제 StoreKit 가격·구매 시트·UMP 시트와 SDK 개인정보 문구는 Mac/iPhone 검증 대상이다.

## 검증

- 공통 398키 × 3언어 키/매개변수 일치와 누락 대체, HTML 바인딩 검사.
- 실제 게임 액션의 성공·실패 결과를 세 언어로 렌더링하고 미치환 매개변수/영어·일본어 내 한국어 혼입/객체 변형 검사.
- 오프라인 시간 단위별 알림, 손상·크기·상위 버전 오류 코드와 상위 버전 원본 보존 검사.
- 브라우저 4177에서 검증된 백업을 UI로 복원해 영어 연구 강화·영구 목표 수령·계약 안내·항로 해금/적용/추적 실행.
- 일본어로 바꾼 직후 마지막 알림 재번역, 기존 항로 7종과 계약 전체 문구, 계약 보상 수령 확인.
- 한영일 잘못된 백업 입력 시 해당 언어의 오류와 복원 버튼 비활성 상태 확인.
- 일본어 재로딩 유지와 한국어 연구 상태 복귀 확인. 영어 연구소·영어/일본어 탐사 화면에서 한국어 혼입 없음.
- 320×740 화면에서 연구소·탐사 대화상자 clientWidth/scrollWidth 모두 250px, 페이지 너비 305px로 가로 넘침 없음.
- 콘솔 오류 없음. 고급 테스트 후 테스트 시작 시 백업으로 되돌리고 임시 탭/서버 정리. 사용자 플레이 주소 4174는 조작하지 않았다.

화면 기록: 루트의 `localized-workshop-preview.jpg`, `localized-contract-preview.jpg`.
자동 검사는 `npm run check`, 경제 회귀는 `npm run balance`, 배포 번들은 `npm run build`다.

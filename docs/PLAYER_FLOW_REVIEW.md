# 현재 목표·모듈 안내·일괄 수령

2026-11-17 Windows 구현/검증 기록. 능력치·비용·보상·광고 정책은 변경하지 않았다.
실제 신규 사용자의 이해도·재미를 측정한 플레이테스트 결과는 아니다.

## 구현

- 캠페인은 현재 구역의 현재 과제 1개를 기본 표시한다. 체크박스로 지난/다음 과제를 보고 구역 선택으로 과거 기록을 확인한다.
- 과제의 조건에 따라 채굴/전투/균형 모듈, 스킬 뽑기, 합성, 프레스티지, 연구, 스킬 연계 안내를 표시한다.
- 모듈 과제는 연구소 잠금·미강화·미적용·전환 대기·적용 상태를 구별한다. 전경 집계와 광고/오프라인 제외를 설명한다.
- 이동 버튼은 해당 모듈/연구 카드 또는 메인 성장 버튼을 보여준다. 화면 이동으로 구매·강화·모듈 전환·합성·환생을 실행하지 않는다.
- 현재 과제의 보상 수령 후 다음 과제를 표시하고 포커스를 옮긴다. HUD 갱신 중에는 임의로 포커스를 이동하지 않는다.
- 메인과 탐사창에 완료 보상 수령 버튼을 둔다. 캠페인의 완료된 연속 구간, 영구 목표, 현재 항해 계약을 한 번에 받는다.
- 각 보상은 기존 개별 수령 함수의 잠금/조건/중복 검사를 거친다. 영구 목표·계약은 첫 프레스티지 전 수령할 수 없다.
- 캠페인이 지급하는 외형은 기존대로 받는다. 별도 항로 도전 외형의 해금·장착과 유료 권한은 일괄 수령에 포함하지 않는다.
- 첫 캠페인 보상과 연구소 해금 안내 2개를 추가해 저장되는 1회성 안내가 8개가 됐다.
- 탐사 탭은 320px에서도 2열로 표시한다. 현재 미완료 과제의 사용할 수 없는 수령 버튼은 숨기고 다음 행동을 보여준다.

일괄 수령 한 번에 저장/보상음을 한 번 요청한다. 정기 자동 저장은 기존대로 동작한다.
수령/집계 필드는 기존 캠페인·탐사 상태를 사용하며 새 영구 진행도는 만들지 않는다.
구역 선택/전체 과제 표시/카드 포커스는 UI 세션 상태다. `tutorial.seen`만 알려진 ID 2개를 추가한다.

## 자동 검증

`npm run check`에 `scripts/check-player-flow.mjs`를 추가했다.

- 모든 과제가 완료된 테스트 상태에서 수령 예정 수 40개와 실제 개별 수령 결과가 정확히 일치한다.
- 미완료 캠페인에서 중단, 첫 프레스티지 전 탐사 잠금, 재탭 중복 차단, 백업 복원/프레스티지 후 수령 기록 보존을 검사한다.
- 보상 미리보기/행동 안내가 상태를 수정하지 않으며 외형을 자동 장착하지 않는지 검사한다.
- 과제 지표 전체의 안내를 한영일로 렌더링해 키·매개변수 누락을 검사한다.
- 모듈의 잠금/강화 필요/전환 대기/적용 상태와 새 튜토리얼의 재시작 후 1회성 유지를 검사한다.

한영일 공통 키는 398→424개다. 번역은 초안이며 원어민 검수가 남아 있다.
`npm run check`, `npm run balance`, `npm run build`가 통과했다.
초반 20시드 중앙값은 첫 뽑기 20초/합성 218초/환생 해금 764.5초로 유지된다.
30일 모델은 기존부터 매초 수령 정책이므로 이번 UI 변경으로 반복 실행하지 않았다.

## 브라우저 검증

별도 주소 4177과 검증된 테스트 백업을 사용했다. 기존 사용자 주소 4174는 조작하지 않았다.

- 320×740 영어 화면에서 현재 과제 1개, 전체 과제 토글, 목표에 맞는 모듈 카드 이동을 확인했다.
- 이동 직후 재화/기본 모듈은 그대로였다. 사용자가 직접 강화한 뒤 적용 안내와 실제 과제 집계가 바뀌었다.
- 일본어에서 완료 보상 40개를 한 번에 수령했다. 저장 내보내기로 캠페인 30/목표 7/계약 3개, 캠페인 외형 8개,
  장착 외형/적용 모듈 null을 확인했다. 재시작 후 추가 수령 버튼이 없고 캠페인 30/30이 유지됐다.
- 한국어 메인에서 보상 1개를 받은 뒤 다음 합성 과제로 전환했다. 합성 안내 버튼은 이동만 하며 재료 부족 버튼은 비활성 상태였다.
- 영어/일본어 탐사 대화상자 clientWidth/scrollWidth는 모두 250px, 페이지 너비 305px로 가로 넘침이 없었다. 콘솔 오류도 없었다.
- 테스트 시작 시 백업으로 복원한 뒤 임시 탭/서버를 정리했다.

화면 기록: 루트 `campaign-guidance-preview.jpg`, `module-guidance-preview.jpg`.
남은 검증은 사람의 첫 세션/모듈 선택 이해도, 수령 후 성장 체감, iPhone 터치·VoiceOver 포커스와 글자 크기다.

# 출시 언어와 추가 15개 언어 계획

사용자 확정: v1.0은 `ko`, `en`, `ja`. 현재 게임 UI와 공통 오류의 세 언어 초안을 연결했다. 원어민·실기기 검수 전이므로 출시 번역 완료는 아니다.
2026-11-17 다국어 기반을 구현했다. 출시 번역 전체 완료는 아니다.

현재 완료:

- 연구 효과/전환/강화·탐사/항로 카드/수령/추적/적용·플랫폼 결과·저장 오류·복귀/웨이브 알림을 메시지 키로 연결했다.
- 저장 파싱과 자동 저장 중단은 번역된 문구가 아닌 안정된 오류 키를 판별한다. 표시 언어가 원본 보존/복원 정책에 영향을 주지 않는다.

- `web-prototype/i18n/locales/{ko,en,ja}.json`: 공통 키 430개씩. 번역은 Codex 작성 검수 전 초안이다.
- 메인 HUD/성장 버튼/자원·스킬 18종/보스·연계 표시, 5구역/30과제와 추가 항로 문구, 설정/도움말/상점, 정적 안내와 백업 주요 흐름 연결.
- 설정에서 자동/한국어/English/日本語 선택. 자동은 기기 언어 목록 중 지원 언어를 우선하고 없으면 영어다.
- `settings.locale`은 수동 선택 시 ko/en/ja, 자동일 때 null. 구형 저장은 null로 이전한다.
  언어는 백업/복원에 포함되며 복원 직후 문구와 `html.lang`을 다시 적용한다.
- 문자열은 `textContent`/속성으로 적용하고 번역 HTML은 실행하지 않는다. 숫자는 HUD·연구소·탐사·항로에서 `Intl.NumberFormat`을 사용한다.
- `npm run check`에 키/매개변수 일치, 누락 영어 대체, 저장 이전/복원, 언어별 경제 불변 검사를 포함한다.

남은 작업:

- 연구소·탐사·항로·일반 시스템/플랫폼 오류·복귀 알림의 메시지 키 분리는 완료했다. 세부 결과는 `LOCALIZATION_REVIEW.md`를 따른다.
- 전체 표현·용어·수량 문법과 새 콘텐츠 문구 원어민 검수. 설정에는 번역 검수 중임을 표시한다.
- StoreKit 가격/SDK 오류/실제 UMP 문구는 네이티브 계층과 함께 검수한다. 게임 언어 선택은 스토어 계정 언어를 바꾸지 않는다.
- Gemini 결과의 키가 현재 키와 다르면 의미·매개변수 기준으로 대조한다. 자동 덮어쓰거나 ID/효과를 바꾸지 않는다.
- 전체 키 원어민 검수, 모든 상태의 320px/영어 확장/일본어 줄바꿈 및 iPhone 접근성 검증.

브라우저에서 한→영→일 전환, 일본어 재시작 유지, 백업의 일본어 설정 복원과 320px 설정창을 확인했다.
영어/일본어 320px 설정창의 가로 넘침이 없었고, 자동 선택 시 기기 한국어로 복귀했다.
일본어 스킬 획득 이름과 알림도 실제 조작으로 확인했다. 별도 테스트 주소를 사용해 기존 플레이 저장을 보존했다.
최종 새 탭 로드/설정 열기에서 콘솔 오류가 없었다. `localization-preview.jpg`는 최종 일본어 설정의 데스크톱 화면 기록이다.
`npm run check`, `npm run balance`, `npm run build`가 통과했다. 초반 20시드 모델에서
첫 뽑기 20초/첫 합성 218초/환생 해금 764.5초 중앙값을 확인했다. 실제 사용자 리텐션 검증은 아니다.
Gemini 결과를 수령해 콘텐츠와 한영일 문구를 통합했다 (`LAUNCH_CONTENT_REVIEW.md`).
UI 초안은 언어당 51키여서 현재 430키를 덮어쓰지 않고 의미별로 대조했다. 기존 전달 파일은 보존했다.
이번 동적 문구 검증은 `LOCALIZATION_REVIEW.md`에 기록했다.
향후 `npm run gemini:brief`를 실행하면 새 i18n 코드와 세 언어 JSON도 첨부 묶음에 포함한다.

구조는 `locale → key → string` JSON, 문장은 `{amount}`, `{wave}`, `{name}` 같은 명명된 매개변수를 사용한다.
다국어 문장을 조각별로 이어 붙이지 않고 완성된 문장 템플릿으로 관리한다.
`Intl.NumberFormat`을 사용하고, 언어별 복수형이 필요하면 별도 키/규칙을 둔다.
저장 데이터의 스킬/구역/보스 식별자는 바꾸지 않고 표시 이름만 번역 키로 가져온다.
기기 언어 자동 감지 + 수동 언어 선택을 제공하고, 미지원/누락 키는 영어로 대체한다.
개발 검사에서는 ko/en/ja 키 집합과 매개변수 집합이 다르면 실패하게 한다.

공통 범주: navigation, settings, tutorial, resources, skills, modules, research, bosses, campaign,
expeditions, routes, save, errors, shop, ads, privacy. 백업/광고/구매/오류 메시지도 번역 대상이다.
스토어 가격은 번역 파일에서 만들지 않고 StoreKit 현지화 가격을 사용한다.
기존 세이브에 포함된 영문 스킬 이름도 알려진 ID로 조회하여 표시하도록 이전한다.

후속 15개 주요 언어 후보(순서는 시장 성과에 따라 조정):
`zh-Hans`, `zh-Hant`, `es`, `pt-BR`, `fr`, `de`, `it`, `ru`, `ar`, `hi`, `id`, `th`, `vi`, `tr`, `pl`.
이 목록은 출시 후 지원 후보이며 18개 언어를 현재 지원한다고 표시하지 않는다.
아랍어 RTL, 힌디어/태국어 폰트·줄바꿈, 숫자/문장 확장도 받을 수 있게 고정 폭 버튼/이미지 글자를 피한다.
RTL 실제 레이아웃과 각 언어 원어민 검수는 해당 언어 출시 전 별도 완료 조건이다.

필수 검수: 320px 화면, 영어 30~40% 문장 확장, 일본어 줄바꿈, 키보드/스크린리더 라벨,
음량·환생 안내·구매/광고 차이·백업 복원·숫자 자리수 증가. Gemini 번역은 초안이며 자동으로 승인하지 않는다.

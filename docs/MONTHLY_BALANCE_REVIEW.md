# 30일 무광고·무과금 기준선

이 문서는 콘텐츠 통합 전의 과거 기준선이다. 최신 캠페인 포함 결과는 `LAUNCH_CONTENT_REVIEW.md`와 `tools/reports/launch-monthly.json`을 따른다.

2026-11-17, 현재 실행 코드로 `npm run balance:month`를 실행했다.
결과: `tools/reports/monthly-baseline.json`. 신규 5구역/30과제/6스킬/2보스/2연구는 아직 이 모델에 없다.

조건: 정책별 20시드, 30일, 매일 0h/12h 각 6분 방문(하루 12분, 총 6시간 전경 플레이),
부재 중 채굴만 최대 4시간, 복귀/전경에서만 행동. 매초 가챠·합성·모듈·영구 연구 구매,
기존 목표/계약 수령, 현재 해금 조건에서 즉시 환생한다. 광고/구매 없음.
각 정책은 채굴/전투/균형 모듈 하나만 구매한다. 사용자의 실제 행동을 측정한 결과가 아니다.
각 날짜는 그날 두 번째 방문 종료 시점의 보유/진행 상태다. 중앙값은 상위 중앙값이다.

30일 내 최고 W40 도달 수는 채굴 18/20, 전투 17/20, 균형 15/20이었다.
도달한 시드만 계산한 W40 중앙 시점은 각각 약 26.50일 / 24.00일 / 26.50일이다.
이 값은 미도달 시드를 제외한 **조건부** 중앙값이며 모든 사용자 완주 시간으로 해석하면 안 된다.
W45 이상은 세 정책 모두 0/20이다.

성장 속도는 한 달 기준으로 쓸 수 있으나, 전경 플레이 합계 6시간을 장기 대기 시간으로 늘린 것이
재미를 보장하지 않는다. 30일 잔존율이나 광고/IAP 전환을 검증한 결과도 아니다.
현 플레이에는 연구 조기 소진, 비슷한 환생 반복, 무작위 스킬 수집의 선택 부족이 남아 있다.

채택한 다음 방향은 기존 W40 부근 성장 뼈대 위에 5구역/30과제, 보스/연계 선택과 외형 목표를 넣는 것이다.
추가 능력치 보상으로 성장 속도가 달라지므로 새 콘텐츠를 통합한 뒤 모든 시드를 다시 실행한다.
목표는 표준 무과금 정책의 30일 완주율 85% 이상을 검토하고 부족한 정책을 조정하는 것이다.
느린 접속/집중 접속·광고 선택 정책 비교, 새 과제별 도달 시점과 실제 플레이테스트는 아직 남아 있다.

# v1.0 출시 범위 확정

기준: 2026-11-17 사용자 결정. iOS 우선, 무료 다운로드 + IAP/IAA, 자체 서버 없이 출시한다.
이 문서는 첫 출시 범위와 현재 구현 상태를 기록한다. 콘텐츠 통합과 모델 검증은 완료했으며, 남은 현지화·실기기·네이티브 검증은 출시 전 필요하다.

## 플레이 분량과 완주

표준 플레이는 하루 2회 × 5~8분, 약 30일(전경 플레이 약 5~8시간)이다.
5개 구역 × 구역별 6개 순차 탐사 과제 = 30개 캠페인 과제를 제공한다.
과제는 날짜가 아니라 이전 탐사 진행으로 열린다. 빠른 사용자는 일찍 끝낼 수 있고 쉬었다 와도 손해·연속 접속 초기화가 없다.
기존 영구 목표 7개·항해 계약 3종은 유지한다. 캠페인 30개와 기존 목표를 같은 콘텐츠로 중복 집계하지 않는다.

| 구역 | 목표 체험 시점(추정) | 성장 구간 지침 | 새 경험 |
| --- | --- | --- | --- |
| 1 출항 채굴대 | 세션 1~3 | 첫 뽑기·합성, W18 첫 환생 | 자동 채굴 이해, 강화 체감 |
| 2 수정 항로 | 세션 4~8 | W20~26 | 모듈 목적 선택, 수정 보스 단계 |
| 3 공허 경계 | 세션 9~15 | W27~32 | 스킬 연계와 보스 공략, 영구 연구 |
| 4 중력 균열 | 세션 16~23 | W33~36 | 추가 보스 원형, 모듈 간 선택 |
| 5 은하 중심 | 세션 24~30 | W37~40 | 두 번째 추가 보스, 탐사 완주와 외형 |

실제 구역/과제 문구는 `web-prototype/game/data/campaign.json`의 한영일 데이터를 따른다. 위 표는 초기 체험 지침이며 해금 타이머가 아니다.
완주 후에는 자유 항해·계약·기록 갱신을 계속할 수 있다. 시즌 서버, 매일 갱신되는 운영 콘텐츠는 첫 버전에 넣지 않는다.

캠페인 설계 규칙:

- 구역별 과제 6개는 채굴·강화·보스·모듈·연계·구역 완료를 섞고 동일 숫자 반복을 피한다.
- 희귀/최고 등급 스킬 보유, 광고 시청, 결제, 연속 출석은 필수 완료 조건으로 사용하지 않는다.
- 무작위 스킬 과제에는 보통/희귀 등급 대체 경로를 두고, 특정 희귀 스킬을 못 뽑아 막히게 하지 않는다.
- 채굴/격파 과제는 같은 전경 집계 규칙을 쓴다. 소급 적용 여부는 지표별 명시하고 오프라인·광고 보상과 혼합하지 않는다.
- 캠페인 보상은 정해진 횟수의 재료·유물과 외형이다. 영구 무제한 배율은 금지하고 기존 보상과 중복 수령을 검사한다.

## 수익화 범위

첫 출시 IAP는 광고 제거와 서포터 외형 묶음 2종의 비소모성 상품이다.
가격은 현지화 스토어 가격으로 표시하며 실제 가격대와 상품 ID는 App Store Connect에서 확정한다.
유료 재화, 유료 랜덤 뽑기, 구독, 배틀패스, 에너지/목숨 판매는 첫 출시에서 제외한다.

광고는 선택형 보급과 환생 후 전면 광고만 사용한다. 배너·앱 시작 광고는 제외한다.
출시 정책을 구현하고 20시드 모델로 비교했다 (`MONETIZATION_REVIEW.md`).
보급은 첫 파츠 합성 또는 환생 후 열리고, **요청 시점 120초 채굴량과 다음 뽑기 비용 20% 중 큰 값**을 광석으로 지급한다.
소수점은 최종 내림하며 보유 한도를 적용한다. 실제 지급량을 시청 전에 표시하고 성공 완료 후 **5분**을 기다린다.
보급 광석은 전경 채굴 과제에 포함하지 않는다.
전면 광고는 **앱 실행 후 전경 플레이 10분 이후/전경 플레이 최소 8분 간격/앱 실행당 최대 2회**, 환생 보상 안내 이후에만 가능하다.
보상형 광고 완료 후 2분 동안 전면 광고를 막고, no-fill/실패는 노출 횟수를 쓰지 않되 전경 60초 동안 재시도를 막는다.
환생 후 전경 15초의 기회 안에서 안내·대화상자가 사라진 뒤 한 번만 시도하며 복귀/복원 시 대기 기회를 취소한다.
추가 오프라인 배수 광고는 중복 보상/저장 경계가 복잡하므로 첫 버전에서 제외한다.

유료 가치는 긴 세션에서의 전면 광고 제거와 눈에 보이는 외형 선택에서 만든다.
6분씩 접속하는 표준 모델에서는 강제 전면 광고가 없었다. 광고 제거 구매 동기와 수익은 실제 사용자 검증이 필요하다.
보급은 다음 광석 뽑기를 돕되 필수 완료 조건으로 만들지 않는다. 광고 시간 때문에 캠페인 전체 완주가 항상 빨라지지는 않는다.
보스 실패·저장 복원·튜토리얼 안내 중 광고를 끼우지 않으며 광고/동의 실패도 기본 플레이를 막지 않는다.
광고 제거를 구매해도 선택형 보급은 남는다는 점을 상점에 명시한다.
수익/광고 시청률은 실제 사용자 측정 전에는 보장하지 않는다.

## 비주얼·언어·운영 경계

비주얼은 `VISUAL_ASSET_PLAN.md`의 ‘네온 궤도 채굴’로 통일한다.
고해상도 그래픽/영상 제작은 뒤로 미루고 현재 Canvas/SVG/CSS로 기능 구분을 완성한다.
루프 음악과 녹음 음성은 첫 출시에서 제외한다. 효과음은 외부 샘플 없이 생성하는 짧은 신호음으로 통일한다.
실제 iPhone 음질·오디오 중단 검증은 Mac 작업이다.

언어는 ko/en/ja 동시 제공하며 출시 후 15개 언어를 추가할 수 있는 키/매개변수 구조를 쓴다.
Game Center, Firebase, 계정/클라우드 저장, 푸시, 원격 설정은 첫 출시 필수 범위에서 제외한다.

## 완료 판정

1. 위 수량의 실제 데이터/화면/저장 이전이 구현되고 누락 번역·중복 보상 검사가 통과할 것.
2. 30일 무광고·무과금 모델을 다시 실행해 첫 환생 중앙값 10~15분 유지, 정상 정책의 완주율 목표 85% 이상을 검토할 것.
3. 첫날·7일·14일·30일에 다른 성장 선택/과제가 존재하고, 재료 대기만 강요하는 구간을 실제 플레이로 수정할 것.
4. 약한 접속(하루 1회 5분), 표준(2회 6분), 집중(하루 30분), 모듈별 정책을 비교할 것.
5. 한영일 모든 화면·구매/동의 안내·백업 메시지를 검수하고 Windows 회귀 검사와 Mac 실기기 검사에 각각 통과할 것.

캠페인 포함 20시드 모델에서 표준(2회×6분)은 20/20 완주·중앙 약 23.0일, 집중(2회×15분)은 약 14.5일, 가벼운 접속(1회×5분)은 30일에 23/30과제다. 날짜 잠금 없이 약 한 달의 진행을 제공하며 실제 재미·리텐션은 플레이테스트가 필요하다.

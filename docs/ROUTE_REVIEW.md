# 심우주 항로 구현과 검증

이 문서의 시간·경제 불변 비교는 항로만 추가한 시점의 결과다. 후속 보스 단계 변경을
포함한 현재 밸런스는 `BOSS_REVIEW.md`와 `long-term-bosses.json`을 참고한다.

2026-11-17. Gemini 앱의 `Auto Drill Galaxy 게임 기획 및 프로토타입 구현` 대화에서
목표·외형·짧은 문구와 QA 초안을 받았다. 화면 표시 모델은 `4 Hydrogen`이었다.
Codex는 목표 조건·진행 집계·저장·UI·외형을 통합하고 수치와 오류 처리를 검증했다.
원래 능력치 보상 제안(`ENDGAME_DRAFT.md`) 대신 경제에 영향을 주지 않는 외형을 채택했다.

## 적용 범위

프레스티지 5회 또는 최고 웨이브 25에서 해금한다. 탐사 기록의 세 번째 패널에서
목표 추적, 수동 외형 해금, 적용과 기본 외형 복귀를 제공한다. 기한·서버 리셋은 없다.

| 목표 | 조건 | 빔·궤도 외형 |
| --- | --- | --- |
| 성계 경계 돌파 | 최고 웨이브 25 | 새벽 이온 궤적 |
| 베테랑 항해사 | 프레스티지 누적 10회 | 워프 에메랄드 |
| 과부하 채굴 숙련 | 채굴 모듈로 직접 채굴 25,000 | 마그마 앰버 |
| 궤도 소탕 숙련 | 전투 모듈로 적 100기 격파 | 크림슨 펄스 |
| 양자 균형 숙련 | 균형 모듈로 보스 20기 격파 | 아스트랄 화이트 |
| 암흑 성운 개척 | 최고 웨이브 32 | 네뷸라 바이올렛 |
| 은하 중심부 도달 | 최고 웨이브 40 | 솔라 골드 코로나 |

외형마다 색상과 선 패턴을 구분한다. 능력치·비용·드롭·광고 보상을 변경하지 않으며
유료 서포터 함선 색상과 함께 표시할 수 있다. 목표 추적은 HUD 표시만 선택한다.
다른 목표도 조건에 맞으면 동시에 집계한다.

`prestige.routes`에 해금 ID, 추적/적용 ID와 모듈별 누적량을 저장하고 환생 후 유지한다.
환생·최고 웨이브는 기존 기록을 반영하지만 모듈별 과거 기록은 추정하지 않는다.
모듈 집계는 항로 해금 이후 실제 전경 채굴/전투에서만 발생한다.
오프라인 보상·광고 보상·웨이브 보상 광석은 직접 채굴 과제에 더하지 않는다.
세이브는 알려진 ID만 허용하고 카운터를 목표값까지 제한한다.

## 재현과 자동 검사

```sh
npm run check
npm run balance
npm run balance:routes
npm run build
```

`scripts/check-routes.mjs`는 해금 경계, 모듈별 집계, 중복 수령, 외형의 경제 불변,
환생 유지, 저장 왕복·구형 세이브·잘못된 데이터와 선 패턴 구분을 검사한다.
`tools/reports/long-term-routes.json`은 20시드, 1초 간격, 24시간 모델이다.
동일한 기존 플레이 정책의 경제 체크포인트 360개는 기존 보고서와 모두 일치했다.
초기 밸런스 중앙값은 첫 뽑기 20초, 첫 합성 218초, 기본 정책 환생 해금 770.75초다.

다음 표는 채굴 과제 완료 → 전투 과제 완료 → 균형 모듈 순서로 전환하고,
매초 구매·합성·연구·보상 수령과 조건부 환생을 수행하는 연속 플레이 정책의 결과다.
광고·구매는 사용하지 않았다. 실제 사용자의 행동이나 리텐션을 예측한 값은 아니다.

| 이벤트 | 20시드 중앙값 |
| --- | --- |
| 항로 해금 | 35.5분 |
| 채굴 숙련 | 45.6분 |
| 환생 10회 | 60.7분 |
| 전투 숙련 | 73.4분 |
| 웨이브 25 | 76.1분 |
| 균형 숙련 | 120.3분 |
| 웨이브 32 | 2.80시간 |
| 웨이브 40 | 7.63시간 |

이 정책에서는 24시간 내 20/20시드가 7종 모두 달성했다. 균형 모듈 고정 정책은
다른 모듈 과제를 진행할 수 없어 5종까지 달성했다. 4시간마다 5분씩 6회 방문하는
정책에서는 항로 해금 중앙값이 약 12.08시간(벽시계)이고 첫날 수령 중앙값은 0개다.
짧게 접속하는 사용자에게 첫날 충분한 콘텐츠가 제공된다고 단정할 수 없다.

## 화면·저장 검증과 남은 일

브라우저 320/390px에서 가로 넘침, 잠긴 버튼, 해금·적용·목표 추적,
재시작 후 유지와 기존 백업 복원을 확인했다. `mobile-route-preview.jpg`는 실제 사용자
진행이 아닌 시뮬레이션 저장을 이용한 QA 화면이다. 테스트 종료 후 원래 저장을 복원했다.

새 목표는 기존 채굴·격파·환생의 활용 범위를 늘린다. Gemini도 기존 지표 반복이라는
한계를 지적했다. 새로운 보스 패턴/스킬 상호작용과 실제 플레이테스트는 여전히 필요하다.
외형 선호도·가독성·리텐션·과금 전환 개선은 검증하지 않았다.
iPhone에서 궤도 패턴, 유료 함선과 동시 표시, 터치/스크롤, 세이브 영속성을 확인해야 한다.

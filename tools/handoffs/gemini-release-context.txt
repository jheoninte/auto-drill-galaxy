# v1.0 출시 범위 확정

기준: 2026-11-17 사용자 결정. iOS 우선, 무료 다운로드 + IAP/IAA, 자체 서버 없이 출시한다.
이 문서는 첫 출시의 **개발 목표**를 확정한다. 아래 예정 콘텐츠가 현재 실행 코드에 모두 있다는 뜻은 아니다.

## 플레이 분량과 완주

표준 플레이는 하루 2회 × 5~8분, 약 30일(전경 플레이 약 5~8시간)이다.
5개 구역 × 구역별 6개 순차 탐사 과제 = 30개 캠페인 과제를 제공한다.
과제는 날짜가 아니라 이전 탐사 진행으로 열린다. 빠른 사용자는 일찍 끝낼 수 있고 쉬었다 와도 손해·연속 접속 초기화가 없다.
기존 영구 목표 7개·항해 계약 3종은 유지한다. 캠페인 30개와 기존 목표를 같은 콘텐츠로 중복 집계하지 않는다.

| 구역 | 목표 체험 시점(추정) | 성장 구간 지침 | 새 경험 |
| --- | --- | --- | --- |
| 1 출항 채굴대 | 세션 1~3 | 첫 뽑기·합성, W18 첫 환생 | 자동 채굴 이해, 강화 체감 |
| 2 수정 항로 | 세션 4~8 | W20~26 | 모듈 목적 선택, 수정 보스 단계 |
| 3 공허 경계 | 세션 9~15 | W27~32 | 스킬 연계와 보스 공략, 영구 연구 |
| 4 중력 균열 | 세션 16~23 | W33~36 | 추가 보스 원형, 모듈 간 선택 |
| 5 은하 중심 | 세션 24~30 | W37~40 | 두 번째 추가 보스, 탐사 완주와 외형 |

구역 이름은 제작용 확정 가제이며 한영일 문구를 Gemini 초안 후 통일한다. 위 시점은 해금 타이머가 아니다.
완주 후에는 자유 항해·계약·기록 갱신을 계속할 수 있다. 시즌 서버, 매일 갱신되는 운영 콘텐츠는 첫 버전에 넣지 않는다.

캠페인 설계 규칙:

- 구역별 과제 6개는 채굴·강화·보스·모듈·연계·구역 완료를 섞고 동일 숫자 반복을 피한다.
- 희귀/최고 등급 스킬 보유, 광고 시청, 결제, 연속 출석은 필수 완료 조건으로 사용하지 않는다.
- 무작위 스킬 과제에는 보통/희귀 등급 대체 경로를 두고, 특정 희귀 스킬을 못 뽑아 막히게 하지 않는다.
- 채굴/격파 과제는 같은 전경 집계 규칙을 쓴다. 소급 적용 여부는 지표별 명시하고 오프라인·광고 보상과 혼합하지 않는다.
- 캠페인 보상은 정해진 횟수의 재료·유물과 외형이다. 영구 무제한 배율은 금지하고 기존 보상과 중복 수령을 검사한다.

## 수익화 범위

첫 출시 IAP는 광고 제거와 서포터 외형 묶음 2종의 비소모성 상품이다.
가격은 현지화 스토어 가격으로 표시하며 실제 가격대와 상품 ID는 App Store Connect에서 확정한다.
유료 재화, 유료 랜덤 뽑기, 구독, 배틀패스, 에너지/목숨 판매는 첫 출시에서 제외한다.

광고는 선택형 보급과 환생 후 전면 광고만 사용한다. 배너·앱 시작 광고는 제외한다.
현재 코드는 보급 60초 채굴량/3분 대기, 전면 첫 3분 제외/최소 3분 간격이다.
출시 조정 후보는 **보급 120초 채굴량/5분 대기**, 전면 **첫 10분 제외/최소 8분 간격/세션 최대 2회**다.
이는 이번에 확정한 실험 후보이며 아직 코드에 적용하지 않았다. 무과금/무광고 기준을 먼저 통과한 뒤 비교한다.
추가 오프라인 배수 광고는 중복 보상/저장 경계가 복잡하므로 첫 버전에서 제외한다.

유료 가치는 자주 보는 전면 광고 제거와 눈에 보이는 외형 선택에서 만든다.
보급은 다음 뽑기/합성 선택을 앞당기되 필수 벽을 넘기는 열쇠로 만들지 않는다.
보스 실패·저장 복원·튜토리얼 안내 중 광고를 끼우지 않으며 광고/동의 실패도 기본 플레이를 막지 않는다.
광고 제거를 구매해도 선택형 보급은 남는다는 점을 상점에 명시한다.
수익/광고 시청률은 실제 사용자 측정 전에는 보장하지 않는다.

## 비주얼·언어·운영 경계

비주얼은 `VISUAL_ASSET_PLAN.md`의 ‘네온 궤도 채굴’로 통일한다.
고해상도 그래픽/영상 제작은 뒤로 미루고 현재 Canvas/SVG/CSS로 기능 구분을 완성한다.
루프 음악과 녹음 음성은 첫 출시에서 제외한다. 효과음은 외부 샘플 없이 생성하는 짧은 신호음으로 통일한다.
실제 iPhone 음질·오디오 중단 검증은 Mac 작업이다.

언어는 ko/en/ja 동시 제공하며 출시 후 15개 언어를 추가할 수 있는 키/매개변수 구조를 쓴다.
Game Center, Firebase, 계정/클라우드 저장, 푸시, 원격 설정은 첫 출시 필수 범위에서 제외한다.

## 완료 판정

1. 위 수량의 실제 데이터/화면/저장 이전이 구현되고 누락 번역·중복 보상 검사가 통과할 것.
2. 30일 무광고·무과금 모델을 다시 실행해 첫 환생 중앙값 10~15분 유지, 정상 정책의 완주율 목표 85% 이상을 검토할 것.
3. 첫날·7일·14일·30일에 다른 성장 선택/과제가 존재하고, 재료 대기만 강요하는 구간을 실제 플레이로 수정할 것.
4. 약한 접속(하루 1회 5분), 표준(2회 6분), 집중(하루 30분), 모듈별 정책을 비교할 것.
5. 한영일 모든 화면·구매/동의 안내·백업 메시지를 검수하고 Windows 회귀 검사와 Mac 실기기 검사에 각각 통과할 것.

현재 30일 결과는 **기존 코드의 기준선**이며 신규 콘텐츠 적용 후 완주율이나 재미를 검증한 결과가 아니다.
세부 기록은 `MONTHLY_BALANCE_REVIEW.md`, Gemini 전달문은 `GEMINI_RELEASE_BRIEF.md`를 따른다.

# 출시 비주얼 방향과 에셋 목록

방향 확정: **네온 궤도 채굴 / Neon Orbit Mining**.
차분한 짙은 우주 위에서 드릴의 빛과 명확한 성장 피드백이 중심이다.
벡터에 가까운 선명한 도형, 둥근 패널, 간결한 기술 도해 스타일로 통일한다.
고해상도 일러스트·복잡한 3D·픽셀 아트는 현재 제작 범위에 넣지 않는다.

## 공통 규격

- 배경 `#020617`, 패널 `#0f172a`, 기본 글자 `#e2e8f0`, 보조 글자 `#cbd5e1`.
- 채굴/선택 `#67e8f9`, 보스/재료 `#fbbf24`, 전투 `#fb7185`, 영구/고급 연구 `#c4b5fd`.
- 희귀도는 N/R/SR/UR 문자와 테두리 패턴을 병행한다. 색만으로 등급/상태/모듈을 전달하지 않는다.
- 한국어·영어·일본어 문자는 이미지에 굽지 않는다. 텍스트는 DOM, 아이콘은 독립 에셋이다.
- 장식보다 44pt 이상 터치 영역과 읽을 수 있는 비용/보상을 우선한다. 모션 줄이기에서 의미를 잃지 않게 한다.
- 영상/전면 섬광/상시 흔들림은 사용하지 않는다. 애니메이션은 짧은 뽑기·합성·보스 격파 강조로 제한한다.
- 초안은 Canvas/SVG/CSS로 구현한다. 래스터 교체 시 투명 캐릭터 PNG/WebP, 배경 불투명 WebP, 원본은 별도 보관한다.
- 크기 숫자는 제작용 기준이며 최종 iPhone 메모리/번들 크기로 검증한다. 아래 수량은 논리 에셋 수이고 PNG 파일 수가 아니다.

===== docs/LOCALIZATION_PLAN.md =====
# 출시 언어와 추가 15개 언어 계획

사용자 확정: v1.0은 `ko`, `en`, `ja`. 현재 코드의 한국어/영어 혼재는 아직 출시 번역 완료가 아니다.
문구 추출·공통 키·언어 선택·번역 적용·UI 검수를 후속 구현한다.

구조는 `locale → key → string` JSON, 문장은 `{amount}`, `{wave}`, `{name}` 같은 명명된 매개변수를 사용한다.
다국어 문장을 조각별로 이어 붙이지 않고 완성된 문장 템플릿으로 관리한다.
`Intl.NumberFormat`을 사용하고, 언어별 복수형이 필요하면 별도 키/규칙을 둔다.
저장 데이터의 스킬/구역/보스 식별자는 바꾸지 않고 표시 이름만 번역 키로 가져온다.
기기 언어 자동 감지 + 수동 언어 선택을 제공하고, 미지원/누락 키는 영어로 대체한다.
개발 검사에서는 ko/en/ja 키 집합과 매개변수 집합이 다르면 실패하게 한다.

공통 범주: navigation, settings, tutorial, resources, skills, modules, research, bosses, campaign,
expeditions, routes, save, errors, shop, ads, privacy. 백업/광고/구매/오류 메시지도 번역 대상이다.
스토어 가격은 번역 파일에서 만들지 않고 StoreKit 현지화 가격을 사용한다.
기존 세이브에 포함된 영문 스킬 이름도 알려진 ID로 조회하여 표시하도록 이전한다.

후속 15개 주요 언어 후보(순서는 시장 성과에 따라 조정):
`zh-Hans`, `zh-Hant`, `es`, `pt-BR`, `fr`, `de`, `it`, `ru`, `ar`, `hi`, `id`, `th`, `vi`, `tr`, `pl`.
이 목록은 출시 후 지원 후보이며 18개 언어를 현재 지원한다고 표시하지 않는다.
아랍어 RTL, 힌디어/태국어 폰트·줄바꿈, 숫자/문장 확장도 받을 수 있게 고정 폭 버튼/이미지 글자를 피한다.
RTL 실제 레이아웃과 각 언어 원어민 검수는 해당 언어 출시 전 별도 완료 조건이다.

필수 검수: 320px 화면, 영어 30~40% 문장 확장, 일본어 줄바꿈, 키보드/스크린리더 라벨,
음량·환생 안내·구매/광고 차이·백업 복원·숫자 자리수 증가. Gemini 번역은 초안이며 자동으로 승인하지 않는다.

# 30일 무광고·무과금 기준선

현 플레이에는 연구 조기 소진, 비슷한 환생 반복, 무작위 스킬 수집의 선택 부족이 남아 있다.

  const saved = saveState(state);
  if (!saved) state.session.lastRewardSummary = '저장 공간을 확인해 주세요. 현재 진행을 저장하지 못했습니다.';

}

function renderTutorial(dtMs) {
  const step = tutorial.tick(dtMs);
  tutorialBanner.hidden = !step;
  if ((step?.id || null) === currentTutorialId) return;
  currentTutorialId = step?.id || null;
  tutorialBanner.textContent = step?.text || '';
  for (const buttonId of ['gachaBtn', 'mergeBtn', 'prestigeBtn']) {
    document.getElementById(buttonId).classList.toggle('tutorial-target', step?.targetId === buttonId);
  }
}

function updateLoop(now) {
  const dtMs = Math.min(250, now - lastFrameAt);
  lastFrameAt = now;

  if (document.hidden) {
    requestAnimationFrame(updateLoop);
    return;
  }

  if (!platform.busy) {
    advanceMining(state, dtMs);
    const clearedWaves = advanceCombat(state, dtMs);
    for (const cleared of clearedWaves) {
      sceneRenderer.burst(cleared.isBoss);
      if (cleared.isBoss) {
        feedback.show({ label: 'BOSS CLEAR', title: `${cleared.name} 격파`, description: `광석 +${cleared.oreReward} · 플라스마 +1${cleared.bonusLoot.relic ? ' · 유물 +1' : ''}`, rarity: 'boss' });
        audio.play('boss');
      }
    }
    if (!shopDialog.open && !workshopUI.open && !expeditionUI.open && !saveUI.open && !settingsUI.open) {
      feedback.tick(dtMs);
      if (feedback.active) tutorialBanner.hidden = true;
      else renderTutorial(dtMs);
    }
  }
  sceneRenderer.draw(state, dtMs, platform.entitlements.supporter);
  if (now - lastHudAt >= 100) {
    renderHud();
    lastHudAt = now;
  }

  if (now - lastSaveAt >= 5000) {
    persistState();
    lastSaveAt = now;
  }

  requestAnimationFrame(updateLoop);
}

    feedback.show({ label: `${result.skill.rarity} · 누적 ${count}개`, title: result.skill.name, description: describeStatChanges(before, getDerivedStats(state)), rarity: result.skill.rarity });
    audio.play('gacha', { rarity: result.skill.rarity, fromGesture: true });
  }
  persistState();
};

    sceneRenderer.burst();

  }

function renderStore() {
  const container = document.getElementById('products');
  container.replaceChildren();
  document.getElementById('storeStatus').textContent = platform.capabilities.purchases
    ? '상품 가격은 현재 스토어 계정의 통화로 표시됩니다.'
    : '구매 기능은 앱에서 스토어 연결 후 이용할 수 있습니다.';
  for (const entry of PRODUCTS) {
    const product = platform.products.find((item) => item.id === entry.id);
    const owned = platform.entitlements[entry.entitlement];
    const card = document.createElement('section');
    card.className = 'product';
    const title = document.createElement('h3');
    title.textContent = entry.name;
    const description = document.createElement('p');
    description.className = 'stat';
    description.textContent = entry.description;
    const button = document.createElement('button');
    button.textContent = owned ? '보유 중' : product?.displayPrice || '앱에서 이용 가능';
    button.disabled = owned || !product || platform.busy;
    button.onclick = () => storeAction(() => platform.purchase(entry.id));
    card.append(title, description, button);
    container.append(card);
  }
  document.getElementById('restoreBtn').disabled = !platform.capabilities.purchases || platform.busy;
  rewardedButton.hidden = !platform.capabilities.rewardedAds;
  leaderboardButton.hidden = !platform.capabilities.gameCenter;
  document.getElementById('privacyOptionsBtn').hidden = !platform.capabilities.privacyOptions;
  document.getElementById('privacyOptionsBtn').disabled = platform.busy;
}

export function rollWeighted(entries, random = Math.random) {
  const totalWeight = entries.reduce((total, entry) => total + entry.weight, 0);
  let remaining = random() * totalWeight;
  for (const entry of entries) {
    remaining -= entry.weight;
    if (remaining < 0) return entry;
  }
  return entries[entries.length - 1];
}

  ] }

export function getSkillLinks(state) {
  const owned = new Set(state.skills.map((skill) => skill.id));
  return SKILL_LINKS.map((link) => ({ ...link, count: link.skills.filter((id) => owned.has(id)).length,
    active: link.skills.every((id) => owned.has(id)) }));
}

export function getEncounter(state) {
  const wave = state.combat.wave;
  if (wave % 5 !== 0 || state.prestige.runs < 1) return null;
  const pattern = BOSS_PATTERNS[(wave / 5 - 1) % BOSS_PATTERNS.length];
  const halfHp = state.combat.maxAsteroidHp / 2;
  const phaseIndex = state.combat.asteroidHp > halfHp ? 0 : 1;
  const phase = pattern.phases[phaseIndex];
  const link = getSkillLinks(state).find((entry) => entry.id === phase.module);
  const moduleBonus = state.ship.workshop.activeModule === phase.module
    && state.ship.workshop.moduleLevels[phase.module] > 0 ? 0.25 : 0;
  const linkBonus = link.active ? 0.1 : 0;
  return { pattern: pattern.id, phaseIndex, ...phase, link, moduleBonus, linkBonus,
    damageMultiplier: phase.multiplier + moduleBonus + linkBonus,
    boundaryHp: phaseIndex === 0 ? halfHp : 0 };
}

export const createExpeditionState = () => ({
  claimed: [], counters: { bosses: 0, activeOre: 0 },

const finiteCount = (value, max = Number.MAX_SAFE_INTEGER) => Number.isFinite(value) ? Math.max(0, Math.min(max, value)) : 0;
export function hydrateExpeditions(raw) {
  const result = createExpeditionState();
  const ids = (value, entries) => Array.isArray(value) ? [...new Set(value.filter((id) => entries.some((entry) => entry.id === id)))] : [];
  result.claimed = ids(raw?.claimed, MILESTONES);
  result.contractClaimed = ids(raw?.contractClaimed, CONTRACTS);
  result.counters.bosses = Math.floor(finiteCount(raw?.counters?.bosses));
  result.counters.activeOre = finiteCount(raw?.counters?.activeOre);
  for (const entry of CONTRACTS) result.contractProgress[entry.id] = finiteCount(raw?.contractProgress?.[entry.id], entry.target);
  return result;
}

export function getMilestoneProgress(state, entry) {
  const values = { runs: state.prestige.runs, bestWave: state.prestige.bestWave, skills: state.skills.length,
    merges: Math.max(0, state.ship.engine - 1), ...state.prestige.expeditions.counters };
  return Math.min(entry.target, values[entry.metric] || 0);
}

// Record only actual foreground simulation events, never reward grants or offline mining.
export function recordExpeditionMining(state, amount) {
  const expedition = state.prestige.expeditions;
  const gain = finiteCount(amount);
  expedition.counters.activeOre = finiteCount(expedition.counters.activeOre + gain);
  if (isExpeditionUnlocked(state) && state.ship.workshop.activeModule === 'drill') addContractProgress(expedition, 'mining-quota', gain);
}
export function recordExpeditionClear(state, wave) {
  const expedition = state.prestige.expeditions;
  if (wave.isBoss) expedition.counters.bosses = finiteCount(expedition.counters.bosses + 1);
  if (!isExpeditionUnlocked(state)) return;
  if (state.ship.workshop.activeModule === 'lance') addContractProgress(expedition, 'combat-sweep', 1);
  if (state.ship.workshop.activeModule === 'sync' && wave.isBoss) addContractProgress(expedition, 'boss-hunt', 1);
}
function addContractProgress(expedition, id, amount) {
  if (expedition.contractClaimed.includes(id)) return;
  const entry = CONTRACTS.find((entry) => entry.id === id);
  expedition.contractProgress[id] = Math.min(entry.target, expedition.contractProgress[id] + amount);
}
export function resetVoyageContracts(state) {
  const expedition = state.prestige.expeditions;
  expedition.contractProgress = createExpeditionState().contractProgress;
  expedition.contractClaimed = [];
}
export function claimExpeditionReward(state, kind, id) {
  const entries = kind === 'milestone' ? MILESTONES : kind === 'contract' ? CONTRACTS : [];
  const entry = entries.find((entry) => entry.id === id);
  if (!entry || !isExpeditionUnlocked(state)) return { ok: false, message: '첫 프레스티지 후 탐사 기록이 열립니다.' };
  const expedition = state.prestige.expeditions;
  const claimed = kind === 'milestone' ? expedition.claimed : expedition.contractClaimed;
  const progress = kind === 'milestone' ? getMilestoneProgress(state, entry) : expedition.contractProgress[id];
  if (claimed.includes(id)) return { ok: false, message: '이미 수령한 보상입니다.' };
  if (progress < entry.target) return { ok: false, message: '아직 목표를 달성하지 않았습니다.' };
  claimed.push(id);
  for (const [resource, amount] of Object.entries(entry.reward)) {
    if (resource === 'ore') state.profile.ore = Math.min(Number.MAX_SAFE_INTEGER, state.profile.ore + amount);
    else state.loot[resource] = Math.min(Number.MAX_SAFE_INTEGER, state.loot[resource] + amount);
  }
  return { ok: true, message: `${entry.title} 보상을 수령했습니다.` };
}


===== web-prototype/game/lifecycle.js =====
import { hydrateState } from './state.js';
import { applyOfflineProgress } from './systems.js';

// Capture once: pagehide/visibilitychange may both fire; SDK saves can occur while hidden.
export function createLifecycle(state, persist, now = Date.now) {
  let snapshot = null;
  return {
    suspend({ busy = false } = {}) {
      if (snapshot) return;
      snapshot = { state: hydrateState(state), busy };
      snapshot.state.profile.lastSeenAt = now();
      persist();
    },
    resume({ busy = false } = {}) {
      if (!snapshot) return false;
      const previous = snapshot;
      snapshot = null;
      if (!previous.busy && !busy) {
        const ore = previous.state.profile.ore;
        applyOfflineProgress(previous.state, now());
        const gain = previous.state.profile.ore - ore;
        state.profile.ore += gain;
        state.profile.totalOreMined += gain;
        if (gain > 0) state.session.lastRewardSummary = previous.state.session.lastRewardSummary;
      }
      state.profile.lastSeenAt = now();
      persist();
      return true;
    }
  };
}

  if (getRouteProgress(state, entry) < entry.target) return { ok: false, message: '아직 목표를 달성하지 않았습니다.' };
  routes.claimed.push(id);
  return { ok: true, message: `${entry.theme} 외형을 해금했습니다. 적용 버튼으로 선택하세요.` };
}
export function trackRoute(state, id) {
  if (id !== null && (!isRouteUnlocked(state) || !ROUTES.some((entry) => entry.id === id))) return { ok: false, message: '지금 선택할 수 없는 목표입니다.' };
  state.prestige.routes.tracked = id;
  return { ok: true, message: id ? '선택한 목표를 메인 화면에 표시합니다. 다른 항로의 진행도도 유지됩니다.' : '목표 추적을 해제했습니다.' };
}
export function equipRoute(state, id) {

  state.prestige.routes.equipped = id;
  return { ok: true, message: id ? `${ROUTES.find((entry) => entry.id === id).theme} 적용. 채굴량과 공격력은 그대로입니다.` : '기본 항로 외형을 적용했습니다.' };
}

export function hydrateState(rawState) {
  const state = createInitialState();
  if (!rawState || typeof rawState !== 'object') return state;

  const number = (value, fallback = 0, min = 0, max = Number.MAX_SAFE_INTEGER) =>
    Number.isFinite(Number(value)) && value !== null ? Math.min(max, Math.max(min, Number(value))) : fallback;
  const integer = (value, fallback = 0, min = 0, max = Number.MAX_SAFE_INTEGER) => Math.floor(number(value, fallback, min, max));
  for (const key of ['ore', 'darkMatter', 'totalOreMined']) state.profile[key] = number(rawState.profile?.[key]);
  state.profile.lastSeenAt = number(rawState.profile?.lastSeenAt, Date.now());
  for (const key of ['hull', 'engine', 'reactor']) state.ship[key] = integer(rawState.ship?.[key], 1, 1);
  state.ship.workshop = hydrateWorkshop(rawState.ship?.workshop);
  for (const key of ['iron', 'crystal', 'plasma', 'relic']) {
    const value = rawState.loot?.[key];
    state.loot[key] = Number.isFinite(value) ? Math.max(0, Math.min(Number.MAX_SAFE_INTEGER, Math.floor(value))) : 0;
  }
  state.prestige.runs = integer(rawState.prestige?.runs);
  state.prestige.bestWave = integer(rawState.prestige?.bestWave, 1, 1, 1000);
  state.prestige.expeditions = hydrateExpeditions(rawState.prestige?.expeditions);
  state.prestige.routes = hydrateRoutes(rawState.prestige?.routes);
  state.monetization.lastRewardedAt = number(rawState.monetization?.lastRewardedAt);
  state.monetization.rewardIds = Array.isArray(rawState.monetization?.rewardIds)
    ? rawState.monetization.rewardIds.filter((entry) => typeof entry === 'string').slice(-100)
    : [];
  state.combat.wave = integer(rawState.combat?.wave, 1, 1, 1000);
  state.prestige.bestWave = Math.max(state.prestige.bestWave, state.combat.wave);
  state.combat.maxAsteroidHp = number(rawState.combat?.maxAsteroidHp, getWaveConfig(state.combat.wave).hp, 1, Number.MAX_VALUE);
  state.combat.asteroidHp = number(rawState.combat?.asteroidHp, state.combat.maxAsteroidHp, 0, state.combat.maxAsteroidHp);
  state.combat.orbitAngle = number(rawState.combat?.orbitAngle, 0, 0, Math.PI * 2);
  state.settings = hydrateSettings(rawState.settings);
  state.tutorial.seen = Array.isArray(rawState.tutorial?.seen)
    ? [...new Set(rawState.tutorial.seen.filter((entry) => TUTORIAL_IDS.includes(entry)))]
    : [];
  state.skills = Array.isArray(rawState.skills)
    ? rawState.skills
        .filter((entry) => entry && typeof entry === 'object')
        .map((entry) => ({
          id: typeof entry.id === 'string' ? entry.id : `skill-${Math.random().toString(36).slice(2, 8)}`,
          name: typeof entry.name === 'string' ? entry.name : 'Unknown Skill',
          rarity: typeof entry.rarity === 'string' ? entry.rarity : 'N',
          miningBonus: number(entry.miningBonus),
          damageBonus: number(entry.damageBonus),
          critBonus: number(entry.critBonus, 0, 0, 1)
        }))
    : [];

  const hpRatio = state.combat.asteroidHp / state.combat.maxAsteroidHp;
  state.combat.maxAsteroidHp = getWaveConfig(state.combat.wave).hp;
  state.combat.asteroidHp = state.combat.maxAsteroidHp * hpRatio;

  return state;
}


===== web-prototype/game/storage.js =====
import { createInitialState, hydrateState, SAVE_KEY } from './state.js';
import { applyOfflineProgress } from './systems.js';

export const BACKUP_KEY = `${SAVE_KEY}-backup`;
export const RECOVERY_KEY = `${SAVE_KEY}-recovery`;
export const BEFORE_RESTORE_KEY = `${SAVE_KEY}-before-restore`;
const FORMAT = 'auto-drill-galaxy';
const VERSION = 1;
const MAX_BYTES = 2_000_000;

// Detect accidental truncation/edits, not a security or anti-cheat signature.
function checksum(text) {
  let hash = 2166136261;
  for (let i = 0; i < text.length; i++) hash = Math.imul(hash ^ text.charCodeAt(i), 16777619);
  return (hash >>> 0).toString(16);
}

export function serializeState(state, now = Date.now()) {
  const clean = hydrateState(state);
  clean.profile.lastSeenAt = now;
  const { session, ...data } = clean;
  const payload = JSON.stringify(data);
  return JSON.stringify({ format: FORMAT, version: VERSION, checksum: checksum(payload), payload });
}

export function parseSave(text) {
  if (typeof text !== 'string' || text.length > MAX_BYTES) throw new Error('백업 크기를 확인해 주세요.');
  let value;
  try { value = JSON.parse(text); } catch { throw new Error('백업 형식을 읽을 수 없습니다.'); }
  if (value?.format !== undefined || value?.version !== undefined) {
    if (value.format !== FORMAT || value.version !== VERSION) throw new Error('지원하지 않는 백업 버전입니다. 최신 앱에서 확인해 주세요.');
    if (typeof value.payload !== 'string' || checksum(value.payload) !== value.checksum) throw new Error('백업이 손상되었습니다.');
    try { value = JSON.parse(value.payload); } catch { throw new Error('백업 내용이 손상되었습니다.'); }
  }
  if (!value || Array.isArray(value) || !value.profile || !value.ship || !value.combat ||
      typeof value.profile !== 'object' || typeof value.ship !== 'object' || typeof value.combat !== 'object' ||
      !Number.isFinite(value.profile.ore) || !Number.isFinite(value.combat.wave) || value.combat.wave < 1) {
    throw new Error('게임 진행 데이터가 아닙니다.');
  }
  return hydrateState(value);
}

export function createSaveStore(getStorage = () => globalThis.localStorage, now = Date.now) {
  let blocked = false;
  let message = '';
  function load() {
    blocked = false;
    message = '';
    try {
      const storage = getStorage();
      const primary = storage.getItem(SAVE_KEY);
      const backup = storage.getItem(BACKUP_KEY);
      if (!primary && !backup) return createInitialState();
      let state;
      try { state = parseSave(primary); }
      catch (error) {
        // A newer app's save must not be replaced by an older backup automatically.
        if (primary && /버전/.test(error.message)) throw error;
        state = parseSave(backup);
        message = '자동 백업에서 진행을 복구했습니다. 저장 메뉴에서 백업을 보관해 주세요.';
      }
      applyOfflineProgress(state, now());
      if (!save(state)) message = '불러온 진행을 저장하지 못했습니다. 저장 메뉴에서 백업을 보관해 주세요.';
      return state;
    } catch (error) {
      blocked = true;
      message = `저장을 읽지 못해 원본을 보존 중입니다. 자동 저장을 중단했습니다. 저장 메뉴에서 백업을 복원해 주세요.${/버전/.test(error.message) ? ` ${error.message}` : ''}`;
      return createInitialState();
    }
  }
  function save(state) {
    if (blocked) return false;
    try {
      const storage = getStorage();
      const previous = storage.getItem(SAVE_KEY);
      if (previous) {
        let valid = false;
        try { parseSave(previous); valid = true; } catch { /* Preserve unreadable data. */ }
        if (valid) storage.setItem(BACKUP_KEY, previous);
        else if (!storage.getItem(RECOVERY_KEY)) storage.setItem(RECOVERY_KEY, previous);
      }
      const timestamp = now();
      storage.setItem(SAVE_KEY, serializeState(state, timestamp));
      state.profile.lastSeenAt = timestamp;
      if (message.startsWith('진행을 저장하지') || message.startsWith('불러온 진행을')) message = '';
      return true;
    } catch {
      message = '진행을 저장하지 못했습니다. 저장 공간을 확인하고 백업 코드를 보관해 주세요.';
      return false;
    }
  }
  function restore(text, current) {
    const candidate = parseSave(text);
    const timestamp = now();
    // Imported offline time is consumed; ads use the stricter of both histories.
    candidate.profile.lastSeenAt = timestamp;
    candidate.monetization.lastRewardedAt = Math.max(current.monetization.lastRewardedAt, candidate.monetization.lastRewardedAt);
    candidate.monetization.rewardIds = [...new Set([...candidate.monetization.rewardIds, ...current.monetization.rewardIds])].slice(-100);
    const storage = getStorage();
    const originals = { primary: storage.getItem(SAVE_KEY), backup: storage.getItem(BACKUP_KEY) };
    // Both writes must succeed before replacing progress. Retain the first damaged original.
    storage.setItem(BEFORE_RESTORE_KEY, serializeState(current, timestamp));
    if (!storage.getItem(RECOVERY_KEY)) storage.setItem(RECOVERY_KEY, JSON.stringify(originals));
    storage.setItem(SAVE_KEY, serializeState(candidate, timestamp));
    Object.assign(current, candidate);
    blocked = false;
    message = '백업을 복원했습니다. 이전 진행은 복원 전 백업으로 보관했습니다.';
    return current;
  }
  return { load, save, restore, get message() { return message; }, get blocked() { return blocked; },
    readPrevious: () => getStorage().getItem(BEFORE_RESTORE_KEY) };
}

export const saveStore = createSaveStore();
export const loadState = () => saveStore.load();
export const saveState = (state) => saveStore.save(state);

import { ECONOMY, FIRST_RUN_DROPS, SKILL_POOL, LOOT_TABLE, getGachaCost, getPrestigeGate, getWaveConfig, rollWeighted } from './balance.js';
import { getWorkshopEffects, resetVoyageModules } from './workshop.js';
import { recordExpeditionMining, recordExpeditionClear, resetVoyageContracts } from './expeditions.js';
import { recordRouteMining, recordRouteClear } from './routes.js';
import { getEncounter } from './encounters.js';

const MERGE_IRON_COST = ECONOMY.mergeIronCost;
const MERGE_CRYSTAL_COST = ECONOMY.mergeCrystalCost;
const OFFLINE_CAP_MS = ECONOMY.offlineCapMs;

export function getDerivedStats(state) {
  const skillTotals = state.skills.reduce(
    (totals, skill) => {
      totals.miningBonus += Number(skill.miningBonus) || 0;
      totals.damageBonus += Number(skill.damageBonus) || 0;
      totals.critBonus += Number(skill.critBonus) || 0;
      return totals;
    },
    { miningBonus: 0, damageBonus: 0, critBonus: 0 }
  );

  const darkMatter = Math.max(0, state.profile.darkMatter);
  const prestigeEffect = darkMatter / (darkMatter + 10);
  const workshop = getWorkshopEffects(state);
  const miningRate = (
    1.8 +
    state.ship.engine * 0.45 +
    state.ship.reactor * 0.25 +
    skillTotals.miningBonus
  ) * (1 + prestigeEffect) + (1.8 + state.ship.engine * 0.45 + state.ship.reactor * 0.25) * workshop.miningMult + workshop.miningBonus;

  const combatDps = (
    4.5 +
    state.ship.hull * 0.4 +
    state.ship.reactor * 0.8 +
    skillTotals.damageBonus
  ) * (1 + prestigeEffect) + (4.5 + state.ship.hull * 0.4 + state.ship.reactor * 0.8) * workshop.damageMult + workshop.damageBonus;

  const critChance = Math.min(0.65, 0.08 + prestigeEffect * 0.01 + skillTotals.critBonus);

  return {
    miningRate,
    combatDps,
    critChance,
    critMultiplier: 2.2
  };
}

export function advanceMining(state, dtMs) {
  state.ship.workshop.switchRemainingMs = Math.max(0, state.ship.workshop.switchRemainingMs - Math.max(0, dtMs));
  const { miningRate } = getDerivedStats(state);
  const oreGain = miningRate * (dtMs / 1000) * state.session.timeScale;
  state.profile.ore += oreGain;
  state.profile.totalOreMined += oreGain;
  recordExpeditionMining(state, oreGain);
  recordRouteMining(state, oreGain);
}

export function advanceCombat(state, dtMs, random = Math.random) {
  const clearedWaves = [];
  if (!Number.isFinite(dtMs) || dtMs < 0) return clearedWaves;
  let remaining = dtMs / 1000 * state.session.timeScale;
  if (!Number.isFinite(remaining) || remaining < 0) return clearedWaves;
  state.combat.orbitAngle = (state.combat.orbitAngle + remaining * 1.6 * (1 + state.ship.engine * 0.08)) % (Math.PI * 2);
  // Spend time, not overflow damage: phases and newly reached waves have their own multipliers.
  while (remaining > 0 || state.combat.asteroidHp <= 0) {
    if (state.combat.asteroidHp <= 0) {
      clearedWaves.push(resolveWaveClear(state, random));
      continue;
    }
    const { combatDps, critChance, critMultiplier } = getDerivedStats(state);
    const encounter = getEncounter(state);
    const dps = combatDps * (1 + critChance * (critMultiplier - 1)) * (encounter?.damageMultiplier ?? 1);
    if (!Number.isFinite(dps) || dps <= 0) break;
    const boundary = encounter?.boundaryHp ?? 0;
    const secondsToBoundary = (state.combat.asteroidHp - boundary) / dps;
    if (remaining < secondsToBoundary) {
      state.combat.asteroidHp -= dps * remaining;
      break;
    }
    remaining = Math.max(0, remaining - secondsToBoundary);
    state.combat.asteroidHp = boundary;
  }
  return clearedWaves;
}

export function performGacha(state, random = Math.random) {
  const cost = getGachaCost(state);
  if (state.profile.ore < cost) {
    return { ok: false, message: `스킬 뽑기에 광석 ${cost}개가 필요합니다.` };
  }

  state.profile.ore -= cost;
  const roll = rollWeighted(SKILL_POOL, random);
  state.skills.push({ ...roll });
  return { ok: true, message: `${roll.name} 획득!`, skill: { ...roll }, cost };
}

export function performMerge(state) {
  if (state.loot.iron < MERGE_IRON_COST || state.loot.crystal < MERGE_CRYSTAL_COST) {
    return {
      ok: false,
      message: `합성에 철 ${MERGE_IRON_COST}개와 수정 ${MERGE_CRYSTAL_COST}개가 필요합니다.`
    };
  }

  state.loot.iron -= MERGE_IRON_COST;
  state.loot.crystal -= MERGE_CRYSTAL_COST;
  state.ship.engine += 1;
  state.ship.reactor += 1;

  return { ok: true, message: '파츠 합성 완료! 엔진과 리액터가 강화되었습니다.' };
}

export function performPrestige(state) {
  const gate = getPrestigeGate(state);
  if (state.combat.wave < gate) {
    return { ok: false, message: `웨이브 ${gate}에서 프레스티지가 열립니다.` };
  }

  const reward = Math.max(1, Math.floor(state.combat.wave / 4));
  state.profile.darkMatter += reward;
  state.profile.ore = 0;
  state.loot = { iron: 0, crystal: 0, plasma: 0, relic: state.loot.relic };
  resetVoyageModules(state);
  resetVoyageContracts(state);
  state.combat.wave = 1;
  state.combat.maxAsteroidHp = getWaveConfig(1).hp;
  state.combat.asteroidHp = state.combat.maxAsteroidHp;
  state.prestige.runs += 1;

  return { ok: true, message: `프레스티지 완료! 암흑물질 +${reward}` };
}

export function applyOfflineProgress(state, now) {
  const elapsedMs = Math.max(0, now - state.profile.lastSeenAt);
  const cappedMs = Math.min(elapsedMs, OFFLINE_CAP_MS);

  if (cappedMs < 1000) {
    state.profile.lastSeenAt = now;
    return;
  }

  const { miningRate } = getDerivedStats(state);
  const oreGain = miningRate * (cappedMs / 1000);
  state.profile.ore += oreGain;
  state.profile.totalOreMined += oreGain;
  state.profile.lastSeenAt = now;
  state.session.lastRewardSummary = `${formatDuration(cappedMs)} 동안 모은 광석 +${Math.floor(oreGain)}`;
}

export function formatLootSummary(loot) {
  return `철 ${loot.iron} · 수정 ${loot.crystal} · 플라스마 ${loot.plasma} · 유물 ${loot.relic}`;
}

function resolveWaveClear(state, random) {
  const clearedWave = getWaveConfig(state.combat.wave);
  recordExpeditionClear(state, clearedWave);
  recordRouteClear(state, clearedWave);
  const nextWave = state.combat.wave + 1;
  const bonusOre = clearedWave.oreReward;

  state.combat.wave = nextWave;
  state.combat.maxAsteroidHp = getWaveConfig(nextWave).hp;
  state.combat.asteroidHp = state.combat.maxAsteroidHp;
  state.profile.ore += bonusOre;
  state.profile.totalOreMined += bonusOre;
  for (let drop = 0; drop < clearedWave.materialDrops; drop += 1) {
    const guaranteedDrop = state.prestige.runs === 0 ? FIRST_RUN_DROPS[clearedWave.wave - 1] : null;
    state.loot[guaranteedDrop || rollWeighted(LOOT_TABLE, random).id] += 1;
  }
  state.loot.plasma += clearedWave.bonusLoot.plasma;
  state.loot.relic += clearedWave.bonusLoot.relic;

  if (nextWave % 4 === 0 && nextWave > state.prestige.bestWave) {
    state.ship.hull += 1;
  }

  state.prestige.bestWave = Math.max(state.prestige.bestWave, nextWave);
  state.session.lastRewardSummary = clearedWave.isBoss
    ? `${clearedWave.name} 격파! 광석 +${bonusOre} · 플라스마 +1${clearedWave.bonusLoot.relic ? ' · 유물 +1' : ''}`
    : `웨이브 ${nextWave - 1} 돌파! 광석 +${bonusOre}`;
  return { wave: clearedWave.wave, isBoss: clearedWave.isBoss, name: clearedWave.name, oreReward: bonusOre, bonusLoot: { ...clearedWave.bonusLoot } };
}

function formatDuration(durationMs) {
  const totalMinutes = Math.floor(durationMs / 60000);
  const hours = Math.floor(totalMinutes / 60);
  const minutes = totalMinutes % 60;

  if (hours && minutes) return `${hours}시간 ${minutes}분`;
  if (hours) return `${hours}시간`;
  return totalMinutes ? `${minutes}분` : `${Math.floor(durationMs / 1000)}초`;
}

      targetId: () => canMerge() ? 'mergeBtn' : null
    },
    {
      id: 'prestige',
      when: () => state.combat.wave >= getPrestigeGate(state),
      text: () => '프레스티지가 열렸습니다. 파츠·스킬을 유지하고 암흑물질을 얻으세요.',
      targetId: () => 'prestigeBtn'
    }
  ];

  return {
    tick(dtMs) {
      if (current) {
        remainingMs -= Math.max(0, dtMs);
        if (remainingMs > 0) return current;
        current = null;
        return null;
      }
      const next = steps.find((step) => !state.tutorial.seen.includes(step.id) && step.when());
      if (!next) return null;
      current = { id: next.id, text: next.text(), targetId: next.targetId?.() || null };
      remainingMs = 4000;
      state.tutorial.seen.push(next.id);
      onShow();
      return current;
    }
  };

    { damageBonus: 0.5 }, { damageBonus: 1 }, { damageBonus: 1.5 }, { damageBonus: 2 }, { damageBonus: 3 }

export const MODULE_SWITCH_MS = 10000;
export const createWorkshopState = () => ({
  activeModule: null,
  moduleLevels: { drill: 0, lance: 0, sync: 0 },
  researchLevels: { radar: 0, stabilizer: 0 },
  switchRemainingMs: 0
});

export function hydrateWorkshop(raw) {
  const result = createWorkshopState();
  for (const [entries, key] of [[VOYAGE_MODULES, 'moduleLevels'], [PERMANENT_RESEARCH, 'researchLevels']]) {
    for (const entry of entries) {
      const level = raw?.[key]?.[entry.id];
      result[key][entry.id] = Number.isFinite(level) ? Math.max(0, Math.min(entry.levels.length, Math.floor(level))) : 0;
    }
  }
  if (VOYAGE_MODULES.some((entry) => entry.id === raw?.activeModule) && result.moduleLevels[raw.activeModule] > 0) {
    result.activeModule = raw.activeModule;
  }
  result.switchRemainingMs = Number.isFinite(raw?.switchRemainingMs)
    ? Math.max(0, Math.min(MODULE_SWITCH_MS, raw.switchRemainingMs)) : 0;
  return result;
}

export const isWorkshopUnlocked = (state) => state.ship.engine >= 2 || state.prestige.runs > 0;

export function getWorkshopEffects(state) {
  const lab = state.ship.workshop;
  const module = VOYAGE_MODULES.find((entry) => entry.id === lab?.activeModule);
  const effect = { miningMult: 0, damageMult: 0, miningBonus: 0, damageBonus: 0,
    ...module?.levels[lab?.moduleLevels[module.id] - 1] };
  for (const entry of PERMANENT_RESEARCH) {
    const level = entry.levels[(lab?.researchLevels[entry.id] || 0) - 1];
    effect.miningBonus += level?.miningBonus || 0;
    effect.damageBonus += level?.damageBonus || 0;
  }
  return effect;
}

export function upgradeWorkshop(state, kind, id) {
  const entries = kind === 'module' ? VOYAGE_MODULES : kind === 'research' ? PERMANENT_RESEARCH : [];
  const entry = entries.find((item) => item.id === id);
  if (!entry) return { ok: false, message: '알 수 없는 연구입니다.' };
  if (!isWorkshopUnlocked(state)) return { ok: false, message: '첫 파츠 합성 후 연구소가 열립니다.' };
  const lab = state.ship.workshop;
  const levels = kind === 'module' ? lab.moduleLevels : lab.researchLevels;
  const cost = entry.costs[levels[id]];
  if (cost === undefined) return { ok: false, message: '최대 단계입니다.' };
  const resource = kind === 'module' ? 'plasma' : 'relic';
  if (!Number.isFinite(state.loot[resource]) || state.loot[resource] < cost) {
    return { ok: false, message: `${resource === 'plasma' ? '플라스마' : '유물'} ${cost}개가 필요합니다.` };
  }
  state.loot[resource] -= cost;
  levels[id] += 1;
  if (kind === 'module' && !lab.activeModule && lab.switchRemainingMs === 0) {
    lab.activeModule = id;
    lab.switchRemainingMs = MODULE_SWITCH_MS;
  }
  return { ok: true, message: `${entry.name} Lv.${levels[id]} ${kind === 'module' ? '강화' : '연구'} 완료!` };
}

export function selectWorkshopModule(state, id) {
  const lab = state.ship.workshop;
  if (!isWorkshopUnlocked(state)) return { ok: false, message: '첫 파츠 합성 후 연구소가 열립니다.' };
  if (id !== null && !VOYAGE_MODULES.some((entry) => entry.id === id && lab.moduleLevels[id] > 0)) {
    return { ok: false, message: '먼저 해당 모듈을 강화해 주세요.' };
  }
  if (lab.activeModule === id) return { ok: false, message: '이미 적용 중입니다.' };
  if (lab.switchRemainingMs > 0) return { ok: false, message: '전환 대기 중입니다.' };
  lab.activeModule = id;
  lab.switchRemainingMs = MODULE_SWITCH_MS;
  return { ok: true, message: id === null ? '기본 항해로 전환했습니다.' : `${VOYAGE_MODULES.find((entry) => entry.id === id).name} 적용!` };
}

export function resetVoyageModules(state) {
  const researchLevels = state.ship.workshop.researchLevels;
  state.ship.workshop = { ...createWorkshopState(), researchLevels };
}

import { getSoundCue } from './sound-bank.js';

export function createAudioFeedback(isEnabled, getVolume = () => 1) {
  let context = null;
  let master = null;
  let generation = 0;
  const voices = new Set();
  const volume = () => {
    const value = getVolume();
    return isEnabled() && Number.isFinite(value) ? Math.max(0, Math.min(1, value)) : 0;
  };
  function silence() {
    generation += 1;
    for (const voice of voices) {
      try { voice.stop(); } catch {}
    }
    voices.clear();
  }
  function sync() {
    const value = volume();
    if (master) master.gain.setValueAtTime(value, context.currentTime);
    if (value === 0) silence();
  }

  function schedule(kind, rarity) {
    const notes = getSoundCue(kind, rarity);
    if (voices.size + notes.length > 16) silence();
    for (const [index, frequency] of notes.entries()) {
      const startAt = context.currentTime + index * 0.08;
      const oscillator = context.createOscillator();
      const gain = context.createGain();
      oscillator.type = 'sine';
      oscillator.frequency.value = frequency;
      gain.gain.setValueAtTime(0, startAt);
      gain.gain.linearRampToValueAtTime(0.06, startAt + 0.01);
      gain.gain.exponentialRampToValueAtTime(0.001, startAt + 0.2);
      oscillator.connect(gain);
      gain.connect(master);
      voices.add(oscillator);
      oscillator.start(startAt);
      oscillator.stop(startAt + 0.22);
      oscillator.onended = () => { voices.delete(oscillator); oscillator.disconnect(); gain.disconnect(); };
    }
  }

  return {
    play(kind, { rarity, fromGesture = false } = {}) {
      if (volume() === 0) return;
      try {
        const AudioContextClass = window.AudioContext || window.webkitAudioContext;
        if (!context && fromGesture && AudioContextClass) {
          context = new AudioContextClass();
          master = context.createGain();
          master.connect(context.destination);
        }
        if (!context) return;
        sync();
        if (context.state === 'running') schedule(kind, rarity);
        else if (fromGesture) {
          const requestedGeneration = generation;
          context.resume().then(() => {
            if (generation === requestedGeneration && volume() > 0) { sync(); schedule(kind, rarity); }
          }).catch(() => {});
        }
      } catch {}
    },
    sync,
    suspend() {
      silence();
      if (context?.state === 'running') context.suspend().catch(() => {});
    }
  };
}

export function describeStatChanges(before, after) {
  const changes = [];
  const mining = after.miningRate - before.miningRate;
  const damage = after.combatDps - before.combatDps;
  const crit = (after.critChance - before.critChance) * 100;
  if (mining > 0.0001) changes.push(`채굴 +${mining.toFixed(1)}/초`);
  if (damage > 0.0001) changes.push(`공격 +${damage.toFixed(1)}/초`);
  if (crit > 0.0001) changes.push(`치명타 +${crit.toFixed(1)}%p`);
  return changes.join(' · ') || '현재 능력치 상한에 도달했습니다.';
}

    code.focus();

    message.textContent = '현재 진행의 백업 코드입니다. 전체를 복사해 메모나 파일로 보관해 주세요.';
  };
  document.getElementById('reviewBackupBtn').onclick = review;
  document.getElementById('previousBackupBtn').onclick = () => {
    invalidate();
    try {
      const previous = saveStore.readPrevious();
      if (!previous) { message.textContent = '복원 전 백업이 없습니다.'; return; }
      code.value = previous;
      review();
    } catch { message.textContent = '저장 공간에 접근할 수 없습니다.'; }
  };
  apply.onclick = () => {
    if (isBusy() || reviewed === null || reviewed !== code.value) return;
    try {
      saveStore.restore(reviewed, state);
      invalidate();
      message.textContent = saveStore.message;
      onRestore();
    } catch (error) {
      message.textContent = `복원하지 못했습니다. ${error.message} 저장 공간과 백업 코드를 확인해 주세요.`;
    }
  };
  return { get open() { return dialog.open; } };
}

import { getWaveConfig } from '../game/balance.js';
import { getRouteTheme } from '../game/routes.js';
import { getEncounter } from '../game/encounters.js';
import { shouldReduceMotion } from '../game/settings.js';

export function createScene(canvas) {
  const context = canvas.getContext('2d');
  const reducedMotion = matchMedia('(prefers-reduced-motion: reduce)');
  let width = 1;
  let height = 1;
  let burstAgeMs = Infinity;
  let burstColor = '#67e8f9';

  function resize() {
    const bounds = canvas.parentElement.getBoundingClientRect();
    width = Math.max(1, bounds.width);
    height = Math.max(1, bounds.height);
    const pixelRatio = Math.min(devicePixelRatio || 1, 2);
    canvas.width = Math.round(width * pixelRatio);
    canvas.height = Math.round(height * pixelRatio);
    context.setTransform(pixelRatio, 0, 0, pixelRatio, 0, 0);
  }

  return {
    resize,
    burst(isBoss = false) {
      burstAgeMs = 0;
      burstColor = isBoss ? '#fbbf24' : '#67e8f9';
    },
    draw(state, dtMs, supporter) {
      burstAgeMs += dtMs;
      const wave = getWaveConfig(state.combat.wave);
      const route = getRouteTheme(state);
      const encounter = getEncounter(state);
      const motionReduced = shouldReduceMotion(state.settings, reducedMotion.matches);
      const centerX = width * 0.5;
      const hudHeight = encounter ? 115 : 65;
      const centerY = (height - hudHeight) * 0.5;
      const orbitRadius = Math.max(20, Math.min(120, width * 0.35, (height - hudHeight - 15) * 0.38));
      const asteroidRadius = Math.min(68, orbitRadius * 0.55);
      const angle = motionReduced ? -0.7 : state.combat.orbitAngle;
      const shipX = centerX + Math.cos(angle) * orbitRadius;
      const shipY = centerY + Math.sin(angle) * orbitRadius;

      context.clearRect(0, 0, width, height);
      for (let index = 0; index < 100; index += 1) {
        context.fillStyle = index % 8 === 0 ? '#60a5fa' : '#94a3b8';
        context.fillRect((index * 137) % width, (index * 71) % height, 1.5, 1.5);
      }
      context.strokeStyle = route ? `${route.color}88` : wave.isBoss ? '#f59e0b44' : '#60a5fa44';
      context.setLineDash(route?.dash || []);
      context.lineWidth = 1;
      context.beginPath();
      context.arc(centerX, centerY, orbitRadius, 0, Math.PI * 2);
      context.stroke();

      context.strokeStyle = route ? `${route.color}aa` : wave.isBoss ? '#fb923c66' : '#22d3ee66';
      context.lineWidth = 3;
      context.beginPath();
      context.moveTo(shipX, shipY);
      context.lineTo(centerX, centerY);
      context.stroke();
      context.setLineDash([]);

      context.beginPath();
      const corners = wave.isBoss ? 12 : 9;
      for (let index = 0; index <= corners; index += 1) {
        const cornerAngle = index / corners * Math.PI * 2;
        const radius = asteroidRadius * (index % 2 === 0 ? 1 : 0.83);
        const cornerX = centerX + Math.cos(cornerAngle) * radius;
        const cornerY = centerY + Math.sin(cornerAngle) * radius;
        if (index === 0) context.moveTo(cornerX, cornerY);
        else context.lineTo(cornerX, cornerY);
      }
      context.closePath();
      context.fillStyle = wave.isBoss ? '#713f12' : '#334155';
      context.strokeStyle = encounter?.color || (wave.isBoss ? '#fbbf24' : '#64748b');
      context.lineWidth = wave.isBoss ? 3 : 2;
      context.fill();
      context.stroke();

      if (encounter) {
        context.strokeStyle = encounter.color;
        context.lineWidth = 2;
        context.setLineDash(encounter.phaseIndex === 0 ? [6, 4] : []);
        context.beginPath();
        context.arc(centerX, centerY, asteroidRadius + 7, 0, Math.PI * 2);
        context.stroke();
        context.setLineDash([]);
      }

      context.fillStyle = wave.isBoss ? '#fb923c' : '#38bdf8';
      context.beginPath();
      context.arc(centerX, centerY, asteroidRadius * 0.35, 0, Math.PI * 2);
      context.fill();

      context.save();
      context.translate(shipX, shipY);
      context.rotate(Math.atan2(centerY - shipY, centerX - shipX));
      context.fillStyle = supporter ? '#c084fc' : '#67e8f9';
      context.beginPath();
      context.moveTo(17, 0);
      context.lineTo(-11, -11);
      context.lineTo(-5, 0);
      context.lineTo(-11, 11);
      context.closePath();
      context.fill();
      context.restore();

      if (!motionReduced && burstAgeMs < 550) {
        const progress = burstAgeMs / 550;
        context.globalAlpha = 1 - progress;
        context.strokeStyle = burstColor;
        context.lineWidth = 3;
        context.beginPath();
        context.arc(centerX, centerY, asteroidRadius + progress * orbitRadius, 0, Math.PI * 2);
        context.stroke();
        context.globalAlpha = 1;
      }
    }
  };
}

function effectText(effect = {}) {
  const output = [];
  if (effect.miningMult) output.push(`파츠 채굴 ${effect.miningMult > 0 ? '+' : ''}${Math.round(effect.miningMult * 100)}%`);
  if (effect.damageMult) output.push(`파츠 공격 ${effect.damageMult > 0 ? '+' : ''}${Math.round(effect.damageMult * 100)}%`);
  if (effect.miningBonus) output.push(`채굴 +${effect.miningBonus}/초`);
  if (effect.damageBonus) output.push(`공격 +${effect.damageBonus}/초`);
  return output.join(' · ') || '효과 없음';
}

export function createWorkshopUI(state, { onChange, isBusy }) {

        select.disabled = !unlocked || level === 0 || lab.activeModule === entry.id || wait > 0 || isBusy();
      }
    }
  }
  return { render, get open() { return dialog.open; } };

===== web-prototype/platform/services.js =====
import { AD_POLICY, PRODUCTS } from './catalog.js';
import { getDerivedStats } from '../game/systems.js';

const unavailable = () => ({ ok: false, message: '이 기능은 앱 버전에서 지원합니다.' });

export function createPlatformServices({ state, provider = null, persist, now = Date.now }) {
  let busy = false;
  let products = [];
  let entitlements = { removeAds: false, supporter: false };
  let nativeCapabilities = {};
  let consent = { canRequestAds: false, privacyOptionsRequired: false };
  let capabilities = { purchases: false, rewardedAds: false, interstitialAds: false, gameCenter: false, privacyOptions: false };
  const startedAt = now();
  let lastInterstitialAt = startedAt;

  function updateEntitlements(value) {
    entitlements = { removeAds: value?.removeAds === true, supporter: value?.supporter === true };
  }

  function refreshCapabilities() {
    capabilities = {
      purchases: nativeCapabilities.purchases === true,
      rewardedAds: nativeCapabilities.rewardedAds === true && consent.canRequestAds,
      interstitialAds: nativeCapabilities.interstitialAds === true && consent.canRequestAds,
      gameCenter: nativeCapabilities.gameCenter === true,
      privacyOptions: nativeCapabilities.privacyOptions === true && consent.privacyOptionsRequired
    };
  }

  async function exclusive(action) {
    if (busy) return { ok: false, message: '진행 중인 요청이 있습니다.' };
    busy = true;
    try {
      return await action();
    } catch {
      return { ok: false, message: '연결을 확인한 뒤 다시 시도해 주세요.' };
    } finally {
      busy = false;
    }
  }

  return {
    get busy() { return busy; },
    get entitlements() { return { ...entitlements }; },
    get capabilities() { return { ...capabilities }; },
    get products() { return products.map((product) => ({ ...product })); },

    async initialize() {
      if (!provider) return unavailable();
      return exclusive(async () => {
        const result = await provider.initialize();
        nativeCapabilities = result.capabilities || {};
        consent = { canRequestAds: result.consent?.canRequestAds === true, privacyOptionsRequired: result.consent?.privacyOptionsRequired === true };
        refreshCapabilities();
        updateEntitlements(result.entitlements);
        if (capabilities.purchases) {
          const response = await provider.getProducts({ productIds: PRODUCTS.map((product) => product.id) });
          products = (Array.isArray(response.products) ? response.products : []).filter((product) =>
            PRODUCTS.some((entry) => entry.id === product.id) && typeof product.displayPrice === 'string'
          );
        }
        return { ok: true, message: '앱 서비스가 준비되었습니다.' };
      });
    },

    async showPrivacyOptions() {
      if (!capabilities.privacyOptions || typeof provider?.showPrivacyOptions !== 'function') return unavailable();
      return exclusive(async () => {
        consent.canRequestAds = false;
        refreshCapabilities();
        const result = await provider.showPrivacyOptions();
        if (result.shown !== true || typeof result.consent?.canRequestAds !== 'boolean' || typeof result.consent?.privacyOptionsRequired !== 'boolean') {
          return { ok: false, message: '개인정보 선택을 확인하지 못했습니다. 다시 시도해 주세요.' };
        }
        consent = { canRequestAds: result.consent.canRequestAds, privacyOptionsRequired: result.consent.privacyOptionsRequired };
        refreshCapabilities();
        return { ok: true, message: '개인정보 선택을 업데이트했습니다.' };
      });
    },

    async purchase(productId) {
      if (!capabilities.purchases || !products.some((product) => product.id === productId)) return unavailable();
      if (entitlements[PRODUCTS.find((product) => product.id === productId).entitlement]) {
        return { ok: false, message: '이미 보유한 상품입니다.' };
      }
      return exclusive(async () => {
        const result = await provider.purchase({ productId });
        if (result.status === 'pending') return { ok: false, message: '구매 승인을 기다리고 있습니다.' };
        if (result.status !== 'purchased' || result.verified !== true) {
          return { ok: false, message: '구매가 완료되지 않았습니다.' };
        }
        const entitlement = PRODUCTS.find((product) => product.id === productId).entitlement;
        if (result.entitlements?.[entitlement] !== true) {
          return { ok: false, message: '구매 권한을 확인하지 못했습니다. 구매 복원을 시도해 주세요.' };
        }
        updateEntitlements(result.entitlements);
        return { ok: true, message: '구매가 완료되었습니다.' };
      });
    },

    async restorePurchases() {
      if (!capabilities.purchases) return unavailable();
      return exclusive(async () => {
        const result = await provider.restorePurchases();
        if (result.verified !== true) return { ok: false, message: '구매 내역을 확인하지 못했습니다.' };
        updateEntitlements(result.entitlements);
        return { ok: true, message: '구매 내역을 복원했습니다.' };
      });
    },

    async showRewarded() {
      if (!capabilities.rewardedAds) return unavailable();
      if (now() - state.monetization.lastRewardedAt < AD_POLICY.rewardedCooldownMs) {
        return { ok: false, message: '보급품을 받은 뒤 3분 후 다시 이용할 수 있습니다.' };
      }
      return exclusive(async () => {
        const result = await provider.showRewarded({ placement: 'supply' });
        if (result.rewardEarned !== true || typeof result.rewardId !== 'string' || !result.rewardId) {
          return { ok: false, message: '광고 보상이 지급되지 않았습니다.' };
        }
        if (state.monetization.rewardIds.includes(result.rewardId)) {
          return { ok: false, message: '이미 지급된 보상입니다.' };
        }
        const ore = getDerivedStats(state).miningRate * AD_POLICY.rewardedMiningSeconds;
        state.profile.ore += ore;
        state.profile.totalOreMined += ore;
        state.monetization.lastRewardedAt = now();
        state.monetization.rewardIds = [...state.monetization.rewardIds, result.rewardId].slice(-100);
        persist(state);
        return { ok: true, message: `보급품 수령: 광석 +${Math.floor(ore)}` };
      });
    },

    async showInterstitial(placement) {
      if (!capabilities.interstitialAds || entitlements.removeAds || placement !== AD_POLICY.interstitialPlacement) {
        return { ok: false, skipped: true };
      }
      if (now() - startedAt < AD_POLICY.interstitialFirstDelayMs || now() - lastInterstitialAt < AD_POLICY.interstitialCooldownMs) {
        return { ok: false, skipped: true };
      }
      return exclusive(async () => {
        const result = await provider.showInterstitial({ placement });
        if (result.shown === true) lastInterstitialAt = now();
        return { ok: result.shown === true };
      });
    },

    async showLeaderboard() {
      if (!capabilities.gameCenter) return unavailable();
      return exclusive(async () => {
        const result = await provider.showLeaderboard();
        return { ok: result.shown === true, message: result.shown === true ? '리더보드를 열었습니다.' : '로그인 상태를 확인해 주세요.' };
      });
    }
  };
}
